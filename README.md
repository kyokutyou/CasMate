# きゃすメイト (CasMate)

配信中のコメント確認・読み上げ・OBS表示をまとめて行う、Windows向けの配信支援アプリです。

**YouTube Live・Twitch・したらば・jpnkn掲示板**に対応しています。Androidスマホと連携すると、手元でコメントを聞いたり、スマホのカメラ映像やマイク音声をPCへ送ったりできます。

## ダウンロード

Windows用インストーラーとAndroid用APKは、[v0.5.0のリリースページ](https://github.com/kyokutyou/CasMate/releases/tag/v0.5.0)からダウンロードできます。

PC版は **Windows 11（x64）**、Android版は **Android 10以降**が対象です。ソースから起動する場合は、下の「ソースからビルド」を参照してください。

## できること

- **コメントをまとめて確認：** 複数サービスのコメントを一つの一覧に表示します。
- **コメントを読み上げ：** VOICEVOXで読み上げます。PCだけでなく、連携したスマホでも聞けます。
- **OBSに表示：** コメント、配信者の音声認識結果、文字演出、簡易キャラクターを表示します。
- **キャラクターを動かす：** 画像2枚で、読み上げに合わせた口パクとゆっくりした動きを付けられます。
- **スマホと連携して外配信：** 外配信で必要なコメントの閲覧・読み上げ、カメラ・マイク送信、OBS配信開始・終了を操作できます。
- **AIリスナーを参加させる：** Geminiが配信中の会話をもとにコメントします。

## 使い方

1. Windows用インストーラー `CasMate-Setup-<バージョン>.exe` を実行し、きゃすメイトを起動します。
2. 初回の案内で、使いたい機能を選びます。
3. 案内に沿って、コメントの接続先、読み上げ、OBSなどを設定・確認します。
4. ホームで接続状態を確認し、「配信中」でコメントを確認します。

初回の案内は途中で中断できます。再開する場合は **「設定 → アプリ設定 → はじめての設定」** を開いてください。

コメント読み上げには、VOICEVOXを別途インストールしてください。音声変換用のFFmpegはPC版へ同梱するため、別途インストールする必要はありません。

## OBS・スマホ・AIリスナーの設定

- **OBSに表示する：** 「OBS操作」でOBSとの接続を準備し、「OBSにソースを追加」で使いたい表示の「OBSに追加」を押します。見た目は「デザインを編集」から調整できます。[CSSで調整する方法](./docs/guides/obs-custom-css.md)もあります。
- **スマホと連携する：** Android版をインストールし、PCの「スマホ連携」で接続を準備して、表示されたQRコードを読み取ります。LAN・Tailscale・直接接続を利用できます。スマホの映像は、登録済み端末の「映像をOBSに表示」から設定します。
- **AIリスナーを使う：** GeminiのAPIキー、投稿先の連携、音声認識、OBS接続などを準備します。詳しくは[AIリスナーの初回設定手順](./docs/guides/ai-listener-setup.md)を参照してください。

## 注意点

- 開発中のアプリです。すべての環境での動作を保証するものではありません。直接接続など、実機検証が未完了の機能も含みます。
- コメント取得や投稿は、各サービスの仕様変更・利用条件・接続状態によって利用できなくなる場合があります。
- スマホとの接続には、PC・スマホ・ネットワークの準備が必要です。特に直接接続は回線やルーターによって利用できない場合があり、実機検証が未完了の範囲もあります。
- AIリスナーを使うと、会話内容などがGeminiへ送信されます。画像添付を有効にした場合は、選択した映像の画像も送信します。利用条件と送信内容は[AIリスナーの設定手順](./docs/guides/ai-listener-setup.md)で確認してください。
- 音声認識は端末内で動作します。初回利用時は認識モデルのダウンロードが必要です。

## ソースからビルド

PC版には、Windows 11 x64、Git、Node.js、pnpm、.NET 10 SDKと、Visual Studio Build ToolsのC++開発環境（x64・Windows SDK・CMake）が必要です。今回の開発環境はNode.js 24.19.0、pnpm 11.23.0です。

Gitで取得したリポジトリのフォルダーで実行してください。初回の依存取得にはインターネット接続が必要です。

```powershell
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

`pnpm build` はPC版と各ワーカーをビルドします。Windows用インストーラーを生成する場合は `pnpm package:win` を実行します。生成先は `release/` です。

Android版は独立したGradleプロジェクトです。[Androidの開発手順](./android/README.md)と[ネイティブ送受信の開発手順](./native/outdoor/README.md)を参照してください。

独立したOBS着せ替えツールは、`pnpm build:obs-style-editor` または通常ビルドで `dist-tools/obs-style-editor.html` に生成します。EdgeまたはChromeで開いて使えます。

ソースの確認には `pnpm lint`・`pnpm typecheck`・`pnpm test` を利用できます。利用方法は上の設定ガイドを参照してください。
