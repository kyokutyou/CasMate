# Android手書き映像合成仕様

2026-10-13採用。本書が手書きの画面・編集・映像合成・寿命を所有する。既存の撮影・送信・弱回線対策は[外配信仕様](./outdoor-streaming.md)、共通画面は[Android仕様](./android-mobile-client.md)に従う。判断は[ADR 0028](../adr/0028-android-handwriting-overlay.md)を参照する。

## 目的と対象

配信者が送信中の大きなカメラプレビューへ文字や落書きを手書きし、通常時は書いている途中からSRT映像へ載せられるようにする。Android内で合成してエンコードする。PC・OBSは従来の映像として受信する。

- 対象はAndroid 10以降の既存外配信セッション。送信前プレビュー・下書き、キーボード文字・図形、画像保存、再起動後の保持は追加しない。
- 手書き内容をディスク、数値診断、ログ、テレメトリーへ保存・送信しない。合成された映像だけが既存の利用者選択済みSRT送信先へ送られる。

## 手書きモード

- 「映像・マイク」の分類一覧に直接「手書き」を追加する。停止中は無効にして「映像送信を開始すると利用できます」と案内する。手動非表示・映像故障等で編集できない場合も理由を示す。
- 2026-10-14再設計採用: 開く際は設定面を閉じ、通常タブ・診断要約とアプリのタイトル帯を隠す。プレビューでOS安全領域内のアプリ部分全体を満たす。OSのステータスバー・ナビゲーション領域と、通常のカメラ／コメント画面のヘッダーは維持する。
- 左上に閉じる、右上に送信・配信のアイコンを重ねる。半透明背景と48dp以上の操作対象を確保する。警告時の右上入口だけは選択配色の不透明な面を背景にし、明るい映像上でも警告色のアイコンと記号を読めるようにする。警告条件は[Android画面仕様](./android-mobile-client.md#配信中の画面と設定)が所有する。下中央に高さ56dp・各操作48dp以上・左右余白8dp以上・安全領域の下端から12dpの固定道具列を重ね、横スクロールを使わない。順番はペン、消しゴム、色・太さ、元に戻す、全体／中央拡大、全消去。文字ラベルを常設せず、選択中の道具は緑で示し、長押しと読み上げで説明する。
- 色・太さは道具列の上の下部パネルで選び、6色・3段階を維持する。選択すると閉じる。色選択はペンへ戻し、太さの選択は現在の道具を保つ。閉じる・戻る・背景タップで閉じ、入口へフォーカスを戻す。パネル／操作メニュー中は描画と表示操作を止め、遅延入力も取り消す。
- 手書きプレビューだけを1〜6倍に拡大・縮小する。初回は映像中央を表示領域いっぱいに広げる倍率を、GLと同じ整数fitから求める。全体／中央拡大ボタンは、1倍・中央の全体表示と、その時の表示領域に合わせた中央拡大を押すたびに交互に切り替える。最初の押下は全体表示。手動の拡大・移動ではこの順番を変えない。送信映像の縦横比・解像度・文書座標・エンコーダーは変えない。
- 指1本で描画し、2本で連続的なピンチ拡縮と移動を行う。指の中間の映像位置を保って倍率を変え、表示位置は枠外を過度に露出しない範囲へ制限する。指の描画開始は最大80ms待ち、端末のタッチ判定距離を超える移動では先に開始する。開始前に2本指になれば待機入力を破棄し、開始後なら有効な線を完了して表示操作へ移る。全指が離れるまで新しい線を始めない。スタイラスは即時描画し、筆圧を使わず、途中に加わった指を描画・表示操作へ使わない。
- 倍率・表示位置・次の切り替え先は同じ送信セッションのモード開閉・再生成・回転で保持する。終了後の通常プレビューは全体表示へ戻し、新しい送信セッションは中央拡大から始める。映像内部の黒帯には描画でき、送信枠外の表示余白には描画しない。上下の操作から始まった入力を描画・ピンチへ流さない。
- 「閉じる」、Androidの戻る、既存の「送信・配信」入口を利用できる。送信・OBSの確認・権限・独立性を維持する。送信・配信メニューの左上に「戻る」は置かず、閉じる・Androidの戻る・背景タップで手書きへ戻す。モードの背後に通常設定を重ねない。メニュー中は描画を無効にし、Androidの戻るは先にメニューを閉じる。
- カメラのホスト、表示中のプレビュー、前面OBS購読をモード切替だけで破棄・再開始しない。通常のプレビュー／診断の選択を上書きせず、モード終了で復元する。元のプレビューが非表示ならモードの間だけ描画面を接続し、終了で解放する。Activity再生成でも同じセッションのモードを復元する。
- ペン・消しゴム、白／黒／赤／黄／緑／青、細／中／太、元に戻す、全消去を用意する。初期選択はペン・白・中。太さは出力短辺の0.4／0.8／1.6%を基準にし、表示拡縮でも送信上の太さを維持する。消しゴムは触れた部分の手書きだけを消す。
- 全消去は即時操作とし、取り消せる。取り消しは直近最大50操作。色・太さの選択だけでは描画を変えない。線・消去のジェスチャーと全消去を履歴にする。極端に長い入力は有界な内部区間に分割することを認める。
- モード中は親・プレビューの横フリックとピント合わせを止める。入力取消・画面離脱・表示操作は有効な線を完了させ、待機中の線は破棄して遅延入力を残さない。
- 座標は正立後の送信枠全体に固定する。枠外の余白は描画対象外、映像内部の黒帯は描画対象とする。枠境界でクリップし、端末回転・前面カメラで文字を回転・反転させない。カメラに追従して対象物へ固定する機能は含めない。
- 反映待ち・編集禁止理由・局所エラーは上部の小さな重畳表示に置き、専用の空白行を予約しない。エラーには明示的な再試行を置く。状態更新で描画面・操作位置を動かさず、成功トーストは出さない。ツールとスマホ状態表示はSRTへ合成しない。ライト／ダーク・320dp・文字2倍で全操作へ到達できること。

## 状態・寿命

- 編集文書と送信用スナップショットは送信セッションに保持する。モード開閉、タブ往復、端末回転、再生成、画面ロック・他アプリ、SRT再接続で保持する。描画データをActivityの保存Bundleへ入れない。
- 通常時は途中の線も反映し、モードを閉じても映像に残す。通常プレビューは送信に描いた同じリビジョンを使う。OBS表示成功とは区別する。
- 明示停止または実セッション終了で文書・送信版・履歴・入力を破棄してモードを閉じる。旧セッションの入力・非同期処理・GL更新を拒否する。
- 手動非表示では手書きをプレビュー・送信の両方から隠し編集を禁止するが、文書は保持する。明示的な「カメラに戻す」のカメラ準備完了後に最新文書を再表示する。
- 緊急静止の保持完了時に、クリーンなカメラ背景と最後の正常な送信用手書き・診断時刻を固定する。専用モードだけはクリーンな保持背景へ最新の編集文書を重ね、ペン・消しゴム・取り消し・全消去を継続できる。変更が送信版と異なるときは「配信映像への反映待ち」と示す。
- 動画復帰試行では既存のカメラ・診断時刻の動作を維持するが、送信用手書きは固定したままにする。既存コントローラーの同じセッション・試行世代の成功通知後、次の送信描画から最新文書を反映する。保持解除受付、動画の一時状態、試行失敗、再接続、描画再準備だけでは反映待ちを解除しない。
- 反映待ちでモードを閉じた通常プレビューは送信版に戻り、再度開くと編集版を表示する。モード開閉は公開確定操作ではない。

## 描画と障害

- GLの順序は正立したカメラ背景の保持→手書き→診断用時刻。出力／プレビューの別描画は通常時に同じリビジョンを使い、静止中の専用モードだけ編集版を使う。既に線が焼き込まれた画像を編集背景にして二重合成しない。
- 透明テクスチャは再利用し、変更時だけ更新する。Canvasのpremultiplied alphaに合う合成とし、線の端へ黒い縁を作らない。更新待ちは最新優先・有界とし、撮影・音声・SRTを待たせない。
- 履歴は最大50操作・50,000サンプル点とし、長い線は4,096点で内部区間に分割する。古い完了操作を基底画像へ統合し、既に描いた外観を保持する。操作ごとの全面画像を無制限に保存しない。描画資源はセッション終了で解放する。
- ラスター化・アップロード失敗は手書きの局所エラーにし、最後の正常な送信用描画を維持して明示的な再試行を提供する。正常なカメラ・マイク・AAC・SRTを止めない。描画経路全体を維持できない場合は既存の映像局所故障へ渡す。編集版・送信固定版をGL外で保持して再準備後に別々に復元する。
- カメラ故障だけを理由とする保持は、明示再試行による実カメラの準備完了で解除する。既に通信静止の固定がある場合は故障保持と区別し、映像修復後に新しい保持・動画復帰試行を実施して成功を確認する。通常動画状態へ戻っただけで公開せず、反映待ちのまま成功へ到達できなくなることも防ぐ。
- 編集版から送信版へ戻る際のプレビュー更新失敗では、同じGL環境で保持している正常な送信用テクスチャへ戻す。使用できなければカメラ背景と局所エラーを表示し、通常プレビューに非公開の編集版を残さない。
- 通信形式・登録・品質保存・PC状態報告へ新フィールドは加えない。

## 受け入れ条件

1. ペン・色・太さ・部分消去・取り消し・全消去、点と横線、枠外余白、指の開始待ちとタッチ判定距離、即時スタイラス、2本指と残った1本指の誤描画防止、取消・パネル・メニューとの競合を自動検証する。
2. 実GLで不透明・アンチエイリアス線、縦横・4方向・前後カメラ・拡縮、通常出力／プレビューの同一リビジョンと画素一致を検証する。
3. 静止中の編集・消去→モード終了／再開→試行失敗→再保持→成功を検証する。成功前の下書き漏出、古い成功通知、時刻の静止／試行中更新を確認する。
4. 再生成・背景移行・手動非表示／復帰・GL再準備・再接続・終了・長時間入力の有界性を検証する。
5. ライト／ダーク、320dp・文字2倍と状態・エラー時の操作位置、既存の全分類・送信・OBS操作への到達を描画テストで確認する。
   ヘッダーなしの全領域表示、道具の固定位置、色／太さの自動閉じ、拡大・移動後の表示と入力座標の一致、全体／中央拡大の交互切替、メニュー中の移動禁止、モード終了・再生成・セッション変更も検証する。
6. Android単体テスト・lint・デバッグビルドとルートのlint・型チェック・全体テスト・pnpm buildを実行する。配布物は生成しない。
7. 利用できる実機・OBSで、線・消去の反映、連続描画、開閉後の映像・マイク・読み上げ継続を確認する。録画提出を要求せず、未確認範囲・実際の条件を明示する。
