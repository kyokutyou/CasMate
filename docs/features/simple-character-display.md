# 簡易キャラクター表示仕様

2026-10-27、画像の利用者向け表示名は「口を閉じた画像」「口を開けた画像」とする。PNG形式と同じ寸法の条件、登録・解除・プレビューの挙動は維持する。初回設定の案内配置は[初回設定](./initial-setup.md#案内と確認)に従う。

## 問題

配信者は少ない素材で、読み上げに反応しながら静止しすぎないキャラクターをOBSと手元へ表示したい。素材や動きの設定が管理画面を圧迫したり、表示面ごとに口形や動きの位相がずれたりしてはならない。

## 利用者視点の解決策

閉口と口開きの全身静止PNGを各1枚使用する。PCの対象読み上げ音声に応じて2枚を切り替え、上下移動、左右の傾き、呼吸の縦伸縮を全表示面で同じ位相にする。素材と微動は簡易キャラクター設定画面で編集し、通常の管理画面には概要とウィンドウ操作だけを置く。

## 素材

- 閉口PNGを先に登録し、口開きPNGは閉口PNGと幅・高さが完全一致する場合だけ受理する。
- 静止PNGだけを受理する。APNG、WebP、GIF、形式偽装、破損画像を拒否する。透明部分は必須としない。
- 1ファイルは20 MiB以下、幅と高さは各8,192 px以下とする。
- 受理した素材はアプリ管理領域へコピーする。新素材の検証に失敗した場合は以前の参照を維持する。
- 素材登録はPNGの画像データ・チェックサムまで検証する。登録・解除は設定保存キュー内の最新状態へ素材参照だけを反映し、微動・表示・ウィンドウ設定を保持する。口開き登録の寸法は保存時点の閉口素材と照合する。通常管理画面の表示オプション保存とウィンドウの位置保存も、素材・微動を上書きしない。
- 閉口未設定または読込不能時は静止プレースホルダーを表示し、微動させない。
- 口開き未設定または読込不能時も口形判定を継続し、閉口PNGを両レイヤーへ使用する。
- 閉口素材を解除すると閉口・口開き参照を原子的に解除する。口開き素材の解除では口開き参照だけを解除する。いずれも管理素材ファイル自体は削除しない。
- 閉口素材の置換後に既存の口開き素材と寸法が一致しない場合は、閉口素材を採用して口開き参照だけを解除し、管理面へ知らせる。

## 口パク

- 口形は `closed` と `open` の2状態とし、バックエンドを唯一の正として全表示面へ配信する。
- 閉口・口開き画像は両方を同位置にマウントしたまま、不透明度を時間補間せず切り替える。
- 対象はコメント読み上げ用PC音声と、機能別仕様で口パク対象と明示されたシステム案内に限る。スマホ音声、試聴、配信者音声認識、新着コメントだけの受信は対象外とする。
- 40ミリ秒ごとのWAVフレームのRMSを音声全体の最大RMSで正規化し、18%以上で開口、10%以下で閉口、間では直前状態を維持する。状態変更後は80ミリ秒以上保持する。
- 無音、再生停止・終了・エラー、読み上げオフでは閉口する。
- 通知は現在再生中の項目IDと照合し、古い再生または停止済み再生の通知を破棄する。

## 常時微動

- 微動は既定でオンとし、Windowsのアニメーション設定からは自動停止しない。本設定のオン・オフを全表示面の正とする。
- 変形原点は中央下端とする。表示構造は、表示領域の10%固定余白、上下移動、回転、縦伸縮、口形レイヤーの順に入れ子にする。
- 上下は `0 → -設定値 → 0`、傾きは `0 → 右 → 0 → 左 → 0`、呼吸は `scaleY(1) → scaleY(1 + 設定値) → scaleY(1)` を滑らかに無限反復する。
- 極端な縦横比または最大値により10%余白を越えて端が切れることは許容する。

| 設定 | 範囲 | 既定値 |
| --- | ---: | ---: |
| 上下移動 | 0～5% | 0.5% |
| 上下一往復 | 1～20秒 | 3.6秒 |
| 左右の傾き | 0～5度 | 0.4度 |
| 傾き一往復 | 1～20秒 | 5.2秒 |
| 呼吸の縦伸縮 | 0～5% | 1.0% |
| 呼吸一往復 | 1～20秒 | 3.2秒 |

全数値は0.1刻みとする。

## 表示面と同期

OBSへの明示登録と期限付き表示テストは[OBSソース登録仕様](./obs-source-registration.md#obs表示テスト)が所有する。独立キャラクターウィンドウは`presentation=standalone`で識別し、通常同期だけを購読する。

- 対象はOBSキャラクタービュー `/overlay/character`、管理画面の小プレビュー、簡易キャラクター設定画面の大プレビュー、独立キャラクターウィンドウとする。
- 素材、口形、有効な微動設定、共通開始時刻を状態スナップショットとリアルタイム更新で配信する。
- 各表示面は共通開始時刻と現在時刻から各アニメーションの再生位置を算出する。後から開いた表示面と再接続した表示面も同じ位相へ合流する。
- スライダー変更では共通開始時刻を維持する。微動をオフからオンへ戻した場合だけ新しい開始時刻を作り、中立姿勢から同期再開する。
- 60 fps環境で表示面間の位相差を1描画フレーム以内とする。
- OBSと独立キャラクターウィンドウは透明背景とし、素材エラー文や設定操作を描画しない。

## 管理画面と簡易キャラクター設定画面

2026-10-26、クリック透過には背後の画面を操作できることを補足し、微動は「ゆっくり動かす」と説明する。素材の指定・寸法検証・プレビューの契約は維持する。

- 管理画面には小プレビュー、「画像・動きを設定」、独立キャラクターウィンドウの表示切替、最前面、クリック透過だけを置く。共通見出しの説明枠は「キャラクターの表示・ウィンドウと詳細設定を確認します。」の1文とし、素材・微動の編集は既存の別画面で行う。
- `/character/simple/settings` に大プレビュー、閉口・口開きPNGの登録と解除、微動オン・オフ、6スライダー、「標準に戻す」を置く。
- 広い画面では左にプレビュー、右に素材と微動設定を置き、設定をスクロールしてもプレビューを確認できるようにする。720px未満ではプレビュー・設定の順の1列とし、低い画面でも操作を覆わない。微動は「上下」「傾き」「呼吸」の3組にまとめ、各組に「動きの大きさ」「1往復の時間」を置く。値・範囲・刻み・標準値は変更しない。
- 微動欄には「変更はOBS・独立ウィンドウにも即時反映され、自動保存されます」と常設する。口パクテストには「このプレビューのみ・2秒」と明記する。ヘッダーの接続状態は「接続済み／再接続中」とし、微動の「保存待ち／保存中／保存済み／保存失敗」と区別する。
- 保存状態は確保済みの常設領域で示し、後から完了した古い保存で新しい編集を保存済みと表示しない。古い保存のスナップショットや失敗応答で、新しい入力・プレビューを巻き戻さない。現在の保存が失敗した場合は最新の保存済み設定へ戻す。保存・操作失敗は自動消去せず確保済み領域で全文をスクロールして読めるようにし、通知によって操作位置・フォーカスを動かさない。これは継続する状態表示であり、一時的な成功通知や独自トーストを追加しない。共通規則は[管理画面の通知](./management-screen.md#通知で操作位置を動かさない共通ルール)に従う。
- 閉口・口開きPNGは、ファイル選択に加えて各登録欄へのドラッグ＆ドロップで登録できる。ドロップした先の素材種別として1ファイル目を、ファイル選択と同じ検証・登録・エラー処理へ渡す。閉口素材未設定中は、口開き登録欄のファイル選択とドロップを受け付けない。
- 閉口素材未登録時は「まず閉口PNGを登録してください」と案内する。解除操作は画像選択欄から区切った「登録素材の解除」にまとめ、「閉口・口開きを解除」「口開きだけ解除」と対象を明記する。既存の解除条件と処理は変更しない。
- 「口パクをテスト」は、閉口・口開き素材の両方が設定済みの場合だけ操作でき、簡易キャラクター設定画面の大プレビューだけを2秒間、200ミリ秒間隔で開口と閉口に交互に切り替える。開始時は開口、終了時はバックエンドが配信する現在の口形状態に戻す。テスト中の口形は保存せず、他のキャラクター表示面へ配信しない。
- Electronでは標準枠付きの専用ウィンドウを一つだけ開く。既に開いていれば前面化する。閉じる操作は非表示とし、位置とサイズだけを保存する。アプリ起動時は自動表示しない。
- 通常ブラウザでは同じURLを別タブで開く。専用URLにも管理トークンを埋め込み、OBSやスマホの読取専用表示面から設定変更できないようにする。
- 独立キャラクターウィンドウの位置、サイズ、表示状態、最前面、クリック透過は保存し、従来どおり起動時復元と画面外補正を行う。

## 一時プレビューと保存

- スライダー操作は順序を保ち、最大約50ミリ秒間隔で保存前の値を全表示面へ配信する。
- 操作終了時、または入力停止から500ミリ秒後に最終値を一度保存する。
- 保存失敗時は全表示面と両管理面を最後に保存できた微動設定へ戻し、エラーを表示する。
- 「標準に戻す」は6既定値を一括プレビューしてから保存する。

## 設定と移行

- 設定スキーマはv13とし、`character.mode` は `simple`、素材と微動は `character.simple`、ウィンドウ設定は `character` 直下に保存する。

```ts
character: {
  mode: 'simple';
  simple: {
    closedAsset: string | null;
    openAsset: string | null;
    motion: {
      enabled: boolean;
      verticalAmplitudePercent: number;
      verticalPeriodSeconds: number;
      tiltAmplitudeDegrees: number;
      tiltPeriodSeconds: number;
      breathingAmplitudePercent: number;
      breathingPeriodSeconds: number;
    };
  };
  alwaysOnTop: boolean;
  clickThrough: boolean;
  windowVisible: boolean;
  windowBounds: WindowBounds;
  settingsWindowBounds: WindowBounds;
}
```

- 現行設定スキーマ13の素材参照を維持する。旧設定の保全と初期化は[保存と対応版](./local-application.md#compatibility-baseline)に従い、旧素材の参照変換は行わない。
- 移行前設定のバックアップと旧素材ファイルを削除しない。
- 口形状態、微動の共通開始時刻、保存前プレビュー値は永続化しない。

## エラー分離

- 素材、設定保存、専用ウィンドウのいずれかが失敗しても、コメント取得、読み上げ、他の表示面を停止しない。
- 表示面で口開き素材が読めない場合は閉口素材へ戻し、管理面へ状態を通知する。
- WebSocket再接続後は最新スナップショットで素材、口形、微動、共通開始時刻を上書きする。

## テスト条件

1. 静止PNGと完全不透明PNGを受理し、APNG、WebP、GIF、形式偽装、破損、容量・寸法超過を拒否する。
2. 登録順、寸法一致、解除、閉口代用、プレースホルダー、読込失敗を検証する。
3. 現行設定のPNG参照維持と、対応終了設定の退避・初期化、旧素材ファイルと退避ファイルの保持を検証する。
4. 口パク解析値、対象音声、古い通知の破棄、停止・エラー時の閉口を検証する。
5. 微動のキーフレーム、範囲、既定値、オン・オフ、標準復元、位相維持、再開時刻、新規表示面・再接続時の同期を決定論的時刻で検証する。
6. 連続操作のプレビュー順序、最終値保存、500ミリ秒保存、保存失敗時の復元を検証する。
7. Electronの簡易キャラクター設定画面の単一起動、前面化、位置・サイズ復元、非自動表示、画面外復帰と、ブラウザ別タブの管理境界を検証する。
8. Windows 11上でOBS、管理画面、独立キャラクターウィンドウを同時表示し、透明背景、口パク位置、微動同期、10%余白、最大値の端切れを実機確認する。
9. 閉口・口開きの各登録欄へのドロップが対応する素材登録を実行し、口開き登録無効中はドロップを受け付けないことを確認する。
10. 口パクテストが設定画面の大プレビューだけを指定間隔と期間で切り替え、終了時に現在の口形状態へ戻ることを決定論的時刻で確認する。

## 対象外事項

パーツ分割PNG、待機・反応画像、3段階以上または母音別の口形、Live2D、VRM、3Dモデル、感情判定、スマホ音声との口パク同期は対象外とする。全体は [OUT_OF_SCOPE.md](../../OUT_OF_SCOPE.md) を参照する。
