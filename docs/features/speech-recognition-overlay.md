# OBS音声認識表示仕様

登録ダイアログの期限付き見本は[OBS表示テスト](./obs-source-registration.md#obs表示テスト)が所有し、通常の認識処理・履歴・オン／オフを変更しない。

## 問題

配信者は、端末内で確定した自分の認識結果をOBSの配信画面へ表示したい。音声認識プレビューのためだけに起動した認識結果や、マイク、モデル、処理時間などの内部情報を配信画面や他の読取画面へ漏らしてはならない。

## 利用者視点の解決策

専用のOBS音声認識ビューをOBSブラウザソースとして追加する。配信者音声認識がオンの場合だけ最新の確定結果を一時表示し、新しい結果で置き換える。見た目と表示時間は専用設定で調整する。

## 管理画面と設定（2026-10-18採用）

- PC設定のOBS分類に「OBS音声認識表示」を追加し、共通の見出し・戻る操作・説明枠を使用する。説明は「OBSに表示する音声認識の見え方を調整します。」とする。
- 「字幕の表示」「デザインを編集」の順に配置する。2026-10-27、表示時間の見出しと入力名の重複を整理し、見出しを「字幕の表示」、入力名を「表示時間」とする。表示時間は1〜60秒、既定10秒とし、数値の右に「秒 (1〜60 秒)」を並べる。幅不足時だけ折り返す。
- 外観は「デザインを編集」から対象を選択した別ウィンドウで調整する。編集・保存・既存設定の引継ぎは[OBSデザイン編集](obs-style-editor.md#アプリ内のobsデザイン編集)が所有する。表示時間は専用設定へ自動保存し、不正入力・保存失敗・画面移動で保持する。
- この画面にプレビュー、URL案内、表示専用ON/OFFは設けない。
- 保存形式16で専用設定を追加する。対応中の13〜15は検証済みコメント外観の6項目を一度だけコピーし、表示時間10秒で移行する。以後は両設定を独立保存する。原本退避・失敗時保全はローカルアプリケーション仕様に従う。

## 具体的な挙動

### 表示入口と公開範囲

- OBS音声認識ビューは `http://127.0.0.1:{port}/overlay/speech-recognition` で提供する。
- 初期状態は専用REST `GET /api/overlays/speech-recognition/bootstrap`、更新は専用WebSocket `/ws/overlay/speech-recognition` から受け取る。専用WebSocketイベントは接続内で単調増加するリビジョンを持ち、欠落を検出したブラウザは再接続して状態スナップショットを取得する。
- 専用公開面は現在表示の `id`、`text`、`expiresAt` と基本テーマだけを返す。音声認識セッションID、マイク、音声時間、処理時間、モデル、ファイルパス、プレビュー履歴を返さない。
- 汎用の読取専用bootstrapとWebSocket、スマホコメント画面、OBSコメントビュー、OBSキャラクタービューへ表示状態と認識文字列を公開しない。
- 専用公開面は読取専用とし、操作トークンや設定変更操作を提供しない。ループバックのHostとOrigin検証は他のOBSビューと同じ規則に従う。

### 結果の受理と表示期限

- 配信者音声認識の保存設定がオンのときだけ確定した認識結果を受理する。音声認識プレビューだけが開始中の場合は受理しない。
- 新しい非空の結果を受けると、表示中の結果を直ちに置き換える。待ちキューと履歴は持たない。
- 空文字または空白だけの結果を受けると、表示中の結果を直ちに消す。「認識結果なし」は表示しない。
- 表示時間は保存済みの`displayDurationSeconds`秒とし、発話時間には依存しない。秒数変更は次に受理する結果から適用し、表示中の期限・結果は変えない。
- 有効期限に達するとバックエンド状態を空にする。ブラウザもローカル時刻で期限を判定し、接続断中でも期限後は透明にする。
- 配信者音声認識をオフへ変更した時点で表示を直ちに消す。ワーカー障害は配信画面へ表示せず、既存結果は元の期限まで維持する。
- 表示状態、結果、履歴は永続化せず、配信セッション終了時に破棄する。

### 描画と外観

- 背景全体は透明とし、認識文字列をOBSブラウザソースの左下へ左揃えで表示する。外周の余白は12 pxとする。
- OBSブラウザソースの幅に応じて日本語を折り返し、横スクロールせず全文を通常テキストとして描画する。HTML、URL、JavaScriptとして解釈しない。
- 外観は専用の基本テーマまたは保存済み構造化デザインから取得し、変更を再読み込みなしで反映する。コメント表示側の設定変更は反映しない。
- OBSコメント表示の表示モード、表示方向、表示時間、表示項目設定は共用しない。
- OBS側のブラウザソースへ貼り付ける外観見本は[カスタムCSS編集ガイド](../guides/obs-custom-css.md)を参照する。アプリでは構造化デザインを保存し、任意CSS入力・保存やCSSクラス名の固定公開契約は追加しない。
- 管理画面の[「OBSにソースを追加」](./local-application.md#obs用urlの管理画面)から音声認識の専用URLを確認・コピーできる。個別の表示オン設定は設けない。

### 再接続と終了

- 接続時と再接続時は有効期限内の現在表示だけを復元する。期限切れ結果を復元しない。
- 待機後や遅延応答で届いた結果も、画面での受信時の現在時刻で期限を照合し、期限切れなら描画しない。
- 複数のOBSブラウザソースが同じURLを開いた場合、同じ表示状態と外観を受け取る。
- ローカルバックエンドへ接続できない場合は透明のままとし、エラー文を表示しない。
- 初期HTTP応答を待たず専用WebSocket接続を開始する。WebSocketで状態を取得した後の遅いHTTP応答や、切断済み接続の通知で現在状態を巻き戻さない。画面終了で初期HTTP待ちと再接続を取り消す。
- アプリ終了通知を受けた場合は直ちに透明にする。

## 他機能との関係

- 認識結果、オン状態、空文字の意味は [配信者音声認識仕様](./streamer-speech-recognition.md) を参照する。
- コメント表示の設定とは独立し、入力方式のみ [OBSコメント表示仕様](./comment-overlay.md) とそろえる。
- HTTP、WebSocket、ループバック公開、終了順序は [ローカルアプリケーション仕様](./local-application.md) を参照する。

## テスト条件

1. 配信者音声認識がオンの場合だけ結果を受理し、プレビュー単独時は表示しない。
2. 新しい結果が現在表示を置き換え、空文字が直ちに消し、オフ切替が直ちに消す。
3. 発話時間に関係なく設定秒数で消え、秒数変更は次の結果から適用する。
4. 期限後にバックエンド状態とブラウザ表示の両方が消える。
5. 再接続時は期限内の結果だけを復元し、期限切れ結果を復元しない。
6. 汎用読取WebSocket、スマホコメント画面、既存OBSビューへ認識文字列と表示状態が含まれない。
7. 専用RESTとWebSocketが表示用の最小データだけを返す。
8. 専用外観の変更とOBS表示テストが専用設定を使用し、コメント表示の外観とは干渉しない。
9. HTMLを含む認識文字列が実行されず、通常テキストとして描画される。
10. OBS実機で透明背景、左下配置と左揃え、日本語折り返し、複数ブラウザソースの同期を確認する。
11. 13〜15版からの移行・原本退避・再起動後の独立設定保持・現行版欠落拒否を確認する。
12. 専用管理画面の自動保存、範囲外入力・保存失敗・画面移動での保持、デザイン編集入口、プレビュー・URL・専用ON/OFFの不存在を確認する。
13. Electronと通常ブラウザーで両配色・文字拡大・320pxと通常幅の描画と入力エラー時の位置保持、設定一覧からの移動・戻りを確認する。

## 対象外事項

途中結果、履歴表示、コメントとの混在、表示結果の保存、アプリ内の任意CSS入力・保存、表示アニメーション、個別の表示オン設定は対象外である。
