2. OBS設定読込の既存UIテストが全体実行時に5秒でタイムアウトした。入力の全画面検索が1回約0.9秒かかることを計測し、同じラベルを既存の「出力と保存」領域内から毎回検索するよう変更した。同じケースは単独確認で約3.4秒から約0.8秒になり、操作・期待値・待機期限・製品コードは維持した。
