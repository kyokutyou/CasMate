# OBSのコメント・音声認識をカスタムCSSで着せ替える

見た目から探したい場合は、[8ページの図解ガイド（PDF）](../../output/pdf/obs-custom-css-visual-guide.pdf)または[図解ガイド（HTML）](obs-custom-css-visual.html)を開いてください。貼り付け場所、コメントの各部分、文字・色・透明度・余白・字幕位置を図と比較見本で説明しています。

きゃすメイトの表示を、OBSのブラウザソースにある「カスタムCSS」で調整するためのガイドです。色・文字サイズ・背景・余白を変えるだけなら、テンプレート冒頭の「変更する値」を編集すれば使えます。

対象は **きゃすメイト v0.5.0のOBSコメントビューとOBS音声認識ビュー**です。CSSはOBSに保存され、きゃすメイトの設定画面には入力しません。テンプレートは現行の表示要素に合わせた編集用の見本です。将来のアプリ更新で表示要素が変わった場合は、このガイドとテンプレートの対応版を確認してください。

## 標準の付箋スタイルを少しだけ変える

2026-10-18の更新から、コメントの標準表示は「ミントとコーラル・タイト」です。新規設定では本文36px、上下4px・左右6px、間隔8px、背景の不透明度45%、名前と本文だけを表示します。「OBSに追加」はキャンバス全体の大きさでソースを作るため、本文はフルHDでも読みやすい36pxを基準にします。既存の保存済み外観は保持されます。初期の見本に合わせて19pxを保存していた場合は、アプリの文字サイズを36pxへ変更してください。付箋色の循環は基本背景色 `#6ed2ba73` のときに適用され、それ以外の背景色は全件に適用されます。

この標準表示を調整する場合、以下だけをOBSのカスタムCSSへ貼り付けられます。通常のCSS変数の上書きなので `!important` は不要です。すでに別の着せ替えCSSを貼っている場合は控えを取ってから置き換えてください。

```css
:root {
  --cm-padding: 4px 6px;       /* 上下・左右。小さくする例: 2px 4px */
  --cm-gap: 8px;              /* 付箋同士の間隔 */
  --cm-max-width: 440px;      /* 長文が折り返す最大幅 */
  --cm-size: 36px;            /* 本文の文字サイズ。フルHDを基準 */
  --cm-text: #183b3b;         /* 本文の色 */
  --cm-meta-size: 0.58em;     /* 名前・サービス名は本文に比例 */
  --cm-meta-gap: 2px;         /* 名前と本文の間 */
  --cm-tape-color: #fffeeb99; /* テープの色と透明度 */
}
```

全ての付箋を同じ色にする場合は `:root` 内へ `--cm-background: rgba(110, 210, 186, 0.45);` を追加します。`--cm-author-color` で名前の色、`--cm-tilt: 0deg;` で傾きをなくせます。`--cm-tape-display: none;` と `--cm-fold-display: none;` でテープと折り返しを隠せます。枠・角丸・影も後述の `--cm-border`・`--cm-radius`・`--cm-card-shadow` で変更できます。

```css
/* 付箋ごとに別の色を使う例。現在表示中の上からの順番です。 */
.overlay-comments .overlay-comment:nth-child(4n + 1) { --cm-background: #6ed2ba73; }
.overlay-comments .overlay-comment:nth-child(4n + 2) { --cm-background: #ff998b73; }
.overlay-comments .overlay-comment:nth-child(4n + 3) { --cm-background: #f9dd8473; }
.overlay-comments .overlay-comment:nth-child(4n + 4) { --cm-background: #87d3c773; }
```

標準表示では、背景・余白・文字を通常のセレクターからも変更できます。`--cm-app-*` はアプリ設定を渡すための内部フォールバックで、ユーザー側では `--cm-*` を使います。この節はコメント専用です。以下の従来テンプレートとOBS着せ替えツールは、テープや傾きのない別のカード外観を出力します。

## アプリで外観を変える（おすすめ）

管理画面の「OBSコメント表示」または「OBS音声認識表示」から「デザインを編集」を押すと、専用の別ウィンドウが開きます。プレビューを見ながら調整するとアプリに自動保存され、OBS表示へ反映されます。文字や背景を変えるためにCSSを貼り付ける操作は必要ありません。

OBSにカスタムCSSを設定済みの場合、その指定がアプリ側のデザインより優先する場合があります。アプリ側で調整するには、必要なCSSを控えてからOBSのカスタムCSSを見直してください。表示方法・時間・表示項目は元の表示設定画面で変更します。

## 独立HTMLでCSSを作る

CSSを編集せずに調整する場合は、[OBS着せ替えツール](../../dist-tools/obs-style-editor.html)をEdgeまたはChromeで開きます。このHTMLひとつで動き、ネット接続やきゃすメイトへの接続は不要です。開発環境では `pnpm build:obs-style-editor`（または通常の `pnpm build`）で生成します。

1. 「コメント」または「音声認識」を選び、プレビューを見ながら文字・背景・余白などを調整します。「詳細」から影・縁取りなども変えられます。
2. 見本の幅・高さを、OBSブラウザソースの幅・高さにも設定します。プレビューの縮小倍率は確認用です。
3. 「OBS用CSSをコピー」を押し、下記の手順で対応ソースの「カスタムCSS」へ貼り付けます。
4. 続きから編集するには「再編集用設定を保存」でJSONを保存し、次回「再編集用設定を読み込む」で開きます。CSSファイルは再編集用設定の代わりにはなりません。閉じると未保存の編集内容は失われます。

ツールの1件／積み上げ・文章・背景は見本専用です。OBSに表示する方式と項目は、きゃすメイトで設定してください。アプリで隠したサービス名・投稿者名はCSSでは復元できません。フォントはOBSのPCにもインストールされているものを使います。

## 1. テンプレートを選ぶ

| OBSで変えたい表示 | コピーするファイル | 初期の見た目 |
| --- | --- | --- |
| コメント | [comments.css](../templates/obs/comments.css) | 白い本文、青い投稿者名、半透明の濃い背景、角丸カード |
| 音声認識 | [speech-recognition.css](../templates/obs/speech-recognition.css) | 左下の白い太字字幕、半透明の濃い背景 |

2つのファイルは、それぞれ対応するブラウザソースへ貼り付けます。CSSファイルを読み込む設定ではなく、**ファイルの中身を全文コピー**します。Markdownのコード例からコピーする場合は、前後の ` ```css ` と ` ``` ` は含めません。

## 2. OBSに貼り付ける

1. きゃすメイトを起動し、管理画面の「OBS用URL」からコメントまたは音声認識をOBSに追加します。手動登録する場合も、管理画面でコピーした現在のURLを使います。
2. OBSの「ソース」で、対応するブラウザソースを右クリックし、「プロパティ」を開きます。
3. 「ローカルファイル」はオフのまま、きゃすメイトのURLを使います。「カスタムCSS」の現在の内容を、念のためテキストファイルへ控えます。
4. 「カスタムCSS」の内容を選んだテンプレートの全文で置き換え、「OK」を押します。
5. きゃすメイトの登録ダイアログで「OBS表示をテスト」を押し、OBSで見え方を確認します。約5秒間の架空表示なので、色・位置の確認に使えます。コメントの表示項目を隠している場合、その項目はテストでも表示されません。
6. 冒頭の値を変更し、再びテストします。最後に、長いコメント・複数件の積み上げ・実際の音声認識結果でも確認してください。

OBSの「幅」「高さ」は文字が折り返す表示領域です。最初はコメントなら幅600・高さ800、字幕なら幅1600・高さ300などで試し、配信レイアウトに合わせて調整してください。ソースを配信画面上で拡大・縮小すると文字や余白も一緒に拡縮されます。文字だけ変えたい場合はCSSの文字サイズを使います。これらの寸法は例であり、必要な大きさは文章量やフォントによって変わります。

「カスタムCSS」と幅・高さの設定は[OBS公式のブラウザソース説明](https://obsproject.com/kb/browser-source)でも確認できます。

## 3. どの値を変えるか

各ファイルの `:root { ... }` 内で、**コロン `:` の右側からセミコロン `;` の前まで**を編集します。`--cm-` で始まる名前はこのテンプレート用の設定名です。

```css
--cm-size: 36px;
--cm-text: #ffe4a3;
--cm-background: rgba(0, 0, 0, 0.6);
```

この例では文字を36px、文字色を淡い黄色、背景を不透明度60%の黒にします。

### 両方に使える値

| 設定名 | 変わる場所 | 変更例・読み方 |
| --- | --- | --- |
| `--cm-font` | フォント | `"Meiryo", sans-serif`。OBSを動かすPCに入っているフォント名を指定。見つからない場合は後ろの候補を使用 |
| `--cm-size` | 本文・字幕の文字サイズ | `36px`。大きくするほど折り返しが増える |
| `--cm-text` | 本文・字幕の文字色 | `#ffffff`=白、`#222222`=濃い灰色 |
| `--cm-background` | カード・字幕ボックスの背景 | `rgba(0, 0, 0, 0.6)`=半透明の黒。`transparent`=背景なし |
| `--cm-border` | ボックスの枠線 | `2px solid #90d8ff`=青い実線。`none`=枠線なし |
| `--cm-radius` | ボックスの角丸 | `0px`=直角、`20px`=大きい角丸 |
| `--cm-padding` | ボックスの内側余白 | `12px 20px`=上下12px・左右20px。`8px`=四辺8px |
| `--cm-edge` | ソース端とボックスの距離 | `24px`。影や縁取りが端で切れる場合も増やす |
| `--cm-line-height` | 行間 | `1.5`=文字サイズの1.5倍。単位は不要 |
| `--cm-weight` | 本文・字幕の太さ | `400`=通常、`700`=太字。フォントによって使える太さは異なる |
| `--cm-text-shadow` | 文字の影・縁取り | `0 2px 3px rgba(0, 0, 0, 0.8)`=下方向のぼかした黒い影。`none`=なし |
| `--cm-card-shadow` | ボックスの影 | `0 3px 8px rgba(0, 0, 0, 0.4)`。`none`=なし |

`rgba(赤, 緑, 青, 不透明度)` の赤・緑・青は0〜255、最後の値は0〜1です。`0` は完全透明、`1` は完全不透明です。背景だけを薄くしたい場合はこの最後の値を変えます。ボックスに `opacity` を指定すると文字も一緒に薄くなります。

### コメント専用の値

| 設定名 | 変わる場所 | 変更例 |
| --- | --- | --- |
| `--cm-gap` | 積み上げたカードの間隔 | `12px` |
| `--cm-meta-size` | サービス名と投稿者名の段の大きさ | `0.8em`=本文の80%。サービス名はさらにその段の85% |
| `--cm-author-color` | 投稿者名の色 | `#ffd1dc` |
| `--cm-source-color` | サービス名の文字色 | `#ffffff` |
| `--cm-source-background` | サービス名の小さな背景 | `transparent` |
| `--cm-source-display` | サービス名の表示 | `inline-flex`=表示、`none`=非表示 |
| `--cm-author-display` | 投稿者名の表示 | `inline`=表示、`none`=非表示 |
| `--cm-emote-height` | 公式エモートの高さ | `1.45em`=本文サイズの1.45倍 |

アプリ側で非表示にしたサービス名・投稿者名・本文は、CSSでは戻せません。表示したい項目をアプリでオンにしてから装飾してください。サービス名と投稿者名の両方を隠す場合は、アプリ側でオフにすると見出し段の余白もなくなります。

### 音声認識専用の値

| 設定名 | 変わる場所 | 変更例 |
| --- | --- | --- |
| `--cm-max-width` | 字幕ボックスの最大幅 | `900px`。ソースの内側幅より広くはならない |
| `--cm-horizontal` | ボックスの左右位置 | `flex-start`=左、`center`=中央、`flex-end`=右 |
| `--cm-vertical` | ボックスの上下位置 | `flex-start`=上、`center`=中央、`flex-end`=下 |
| `--cm-text-align` | ボックス内の文字揃え | `left`=左揃え、`center`=中央揃え、`right`=右揃え |

左右位置は「ボックスをどこに置くか」、文字揃えは「複数行の文字をどう揃えるか」です。配信画面上の絶対位置は、OBSでブラウザソースそのものを移動して調整します。

## 4. よく使う着せ替え例

以下はテンプレートを貼り付けた後で使います。値の例は、冒頭にある同名の行を置き換えてください。セレクター付きの追加CSSはファイルの最後に追記します。

### 明るいカードにする（両方）

```css
--cm-text: #243247;
--cm-background: rgba(255, 255, 255, 0.94);
--cm-border: 2px solid #a9d8f0;
--cm-text-shadow: none;
```

コメントでは、投稿者名・サービス名も次の値に変えると読めます。

```css
--cm-author-color: #176b91;
--cm-source-color: #243247;
--cm-source-background: #e5f3fb;
```

### 背景なし・縁取り字幕にする（音声認識）

```css
--cm-background: transparent;
--cm-border: none;
--cm-card-shadow: none;
--cm-text-shadow: -2px -2px 0 #000, 2px -2px 0 #000, -2px 2px 0 #000, 2px 2px 0 #000, 0 3px 4px #000;
--cm-horizontal: center;
--cm-text-align: center;
```

背景の動画が明るくても暗くても読みやすくする例です。縁取りを細くしたい場合は各 `2px` を `1px` にします。

### サービスごとにバッジの色を変える（コメント）

次のCSSをコメント用テンプレートの末尾へ追記します。

```css
.overlay-comments .comment-youtube .source-badge {
  background: #b52d46;
  color: #ffffff;
}
.overlay-comments .comment-twitch .source-badge {
  background: #7044b8;
  color: #ffffff;
}
.overlay-comments .comment-shitaraba .source-badge {
  background: #236e57;
  color: #ffffff;
}
```

### 本文だけのシンプルなコメントにする

アプリの「OBSコメント表示」でサービス名と投稿者名をオフにし、本文をオンにします。続いて背景・枠線を好みに合わせて変更します。CSSだけでこのソースの見出しをまとめて隠す場合は、末尾へ次を追記します。

```css
.overlay-comments .comment-meta { display: none; }
```

## 5. さらに編集するときの目印

CSSの `.名前` は、表示のどの部分を変更するかを指定する目印（セレクター）です。以下は現行実装の目印で、固定の公開APIではありません。

| セレクター | 対象 |
| --- | --- |
| `.overlay-comments` | コメント表示領域全体 |
| `.overlay-comments .overlay-comment` | コメント1件の外側のカード |
| `.overlay-comments .comment-meta` | サービス名・投稿者名の段 |
| `.overlay-comments .source-badge` | サービス名 |
| `.overlay-comments .comment-meta strong` | 投稿者名 |
| `.overlay-comments .comment-body` | 本文 |
| `.overlay-comments .emote` | 公式エモート画像 |
| `.overlay-comments .comment-youtube` / `.comment-twitch` / `.comment-shitaraba` | 各サービスのコメント内容。背景ボックスはその外側の `.overlay-comment` |
| `.speech-recognition-overlay` | 音声認識の表示領域全体 |
| `.speech-recognition-overlay .speech-recognition-overlay-text` | 認識結果のボックスと文字 |

従来テンプレートの一部には `!important` が残っています。音声認識ではアプリが直接指定する基本テーマよりCSSを優先するために必要です。コメントの標準付箋表示は内部のフォールバック変数を使うため、上記の変更例では不要です。テンプレート貼り付け後にアプリの基本テーマへ戻したい項目は、該当する値の定義だけでなく、下段の適用する行も削除します。例：文字サイズだけ戻すなら `font-size: var(--cm-size) !important;` を削除します。

CSSで変更できるのは描かれている要素の外観です。表示時間・積み上げ方向・件数・読み上げ同期・認識のオン／オフはアプリ側の機能を使います。通常動作の正式な条件は[OBSコメント表示仕様](../features/comment-overlay.md)、[OBS音声認識表示仕様](../features/speech-recognition-overlay.md)、[表示テスト仕様](../features/obs-source-registration.md#obs表示テスト)を参照してください。

## 6. うまく変わらないとき

| 症状 | 確認すること |
| --- | --- |
| 何も表示されない | 「OBS表示をテスト」で確認。通常時は新着コメントや有効な認識結果がなければ透明。URLと起動状態、ソースの表示も確認 |
| CSSが効かない | コメント用と音声認識用の取り違え、全文の貼り付け、`;` と `}` の抜け、コードブロック記号の混入を確認。必要ならプロパティの「現在のページのキャッシュを更新」を実行 |
| アプリのプレビューは変わらない | CSSはOBSのそのブラウザソースにだけ適用。アプリ内プレビューや通常ブラウザには反映されない |
| フォントが変わらない | OBSのPCへフォントが入っているか、名前が合っているか確認。新しく入れた場合はOBSを再起動 |
| 文字・影が切れる | ソースの幅・高さを増やす、文字サイズや余白を減らす、OBSのクロップを確認。影は外周余白も確保 |
| 長いコメントが画面からはみ出す | 本文・字幕の折り返し指定を残す。大きな文字や長文はソースの高さも必要。5秒の短い見本だけで判断しない |
| 複数シーンの見た目も変わった | 同じOBSソースを参照している場合は設定も共用。別の外観にしたい場合は、別の新規ブラウザソースを手動作成し、同じURLと別のCSSを指定 |
| 元に戻したい | 控えたカスタムCSSへ戻す。アプリの基本テーマを使う場合は、このテンプレートと追加例を取り除く |

## 7. 他の人へ渡す

編集したCSSファイルとこのガイドをセットで渡します。「コメント用」「音声認識用」と対応するきゃすメイトのバージョンを添えてください。受け取った人は、自分のきゃすメイトで表示URLを取得し、自分のOBSソースへCSSを貼り付けます。フォントは各PCへ用意します。

このテンプレートにはURL・接続情報の編集や外部素材の読み込みは不要です。配布時もCSS内に自分の接続情報を入れる必要はありません。
