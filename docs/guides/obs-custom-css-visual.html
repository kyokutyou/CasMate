編集するのは、コロンの右側の「値」

名前・コロン・セミコロンを残して、値を置き換えます。

1行の読み方

--cm-size: 36px;
設定名はそのままこの値を変更; を残す
--cm-font: "Meiryo", sans-serif;
--cm-size: 36px;
--cm-weight: 700;

px は文字の大きさ。700 は太字。
フォント名は、OBSのPCにあるものを指定します。

文字サイズの違い

24px / 小さめ
36px / 大きめ

同じ幅でも、大きい文字は折り返しが増えます。長いコメントでも確認します。

行間も変えられます

2行の字幕です。
行間は1.15倍。

--cm-line-height: 1.15;

2行の字幕です。
行間は1.8倍。

--cm-line-height: 1.8;

文字だけを変えたいときはCSSを編集します。OBSでソースを拡縮すると、文字・枠線・余白も一緒に変わります。

背景の濃さは、rgbaの「最後の値」

0は完全透明、1は完全不透明。背景だけの透明度を調整できます。

rgba(0, 0, 0, 0.5)

赤・緑・青は0〜255。最後の値は不透明度。

余白・角丸・枠線で、カードの形を変える

内側余白は「上下 左右」の順。外周余白はソース端との距離です。

内側余白の読み方

上下の余白左右
そら

カードの内側に余白を作ります。

上下 12px左右 20px
--cm-padding: 12px 20px;
--cm-edge: 24px;

黄色は余白の位置を示す模式図です。
実際の余白もカードの背景色になります。

角丸と枠線の比較

角丸 0px

角丸 20px

--cm-radius: 20px;
--cm-border: 2px solid #90d8ff;

2px = 太さ、solid = 実線、#90d8ff = 色。

積み上げの間隔

間隔
--cm-gap: 14px;
影や文字の縁取りが切れるときは、--cm-edge を増やし、OBS側のクロップも確認します。

字幕の位置と、文字揃えは別々に選べる

ボックスの位置は horizontal / vertical。中の文字は text-align。

左下

配信を始めます。
--cm-horizontal: flex-start;
--cm-vertical: flex-end;
--cm-text-align: left;

中央下

配信を始めます。
--cm-horizontal: center;
--cm-vertical: flex-end;
--cm-text-align: center;

右上

配信を始めます。
--cm-horizontal: flex-end;
--cm-vertical: flex-start;
--cm-text-align: right;

中央のボックス、左揃えの文字

複数行の字幕です。
文字は左端を揃えます。

horizontal: center / text-align: left

中央のボックス、中央揃えの文字

複数行の字幕です。
文字も中央に揃えます。

horizontal: center / text-align: center

上下・左右はブラウザソースの中での位置です。配信画面上の位置はOBSでソースを移動して調整します。
