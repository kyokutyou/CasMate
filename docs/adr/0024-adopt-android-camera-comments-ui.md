# ADR 0024: Androidのカメラとコメントの機能別画面を採用する

- 状態: 採用（2026-10-07）

## 背景

共通操作を両タブへ置く画面ではコメント閲覧時にも撮影操作が並ぶ。利用者が比較見本の「下部に操作」を選び、機能の分離、フリックによる移動、不要な説明欄の削除、通信断で位置を動かさない表示、初回QR登録と配色を採用した。

同日の実装後、ヘッダーとフッターが大きいという指摘から再比較し、利用者が「切替を上部へ」を採用した。移動を上部、機能操作を下部へ分けることで、下部タブと重複した見出しの占有面積を減らす。

さらに両画面の本文が見づらいという指摘からフッターなしを比較し、利用者が1案「操作を上部に集約」を採用した。下部の常設操作領域を撤去し、右上の一時的な機能別メニューから既存の操作と設定へ進む。ライト配色は採用見本に合わせる。追加確認でAndroidのコメント本文・カードも見本の配色を優先し、PCの保存値と通常ブラウザの表示を保持することを採用した。

## 判断

カメラとコメントを分け、上部タブと左右フリックで移動する。撮影・映像送信・OBS操作はカメラの右上メニュー、一覧・読み上げはコメントへ置く。追加採用でコメントのヘッドホンは読み上げON／OFFの直接操作とし、操作ウィンドウを削除する。利用者が選択した左隣の歯車からコメント設定と状態詳細へ進む。頻繁な開始停止を一操作にし、配色・失敗理由の確認手段も保持する。OSの安全領域を残してアプリフッターを削除する。未登録時はQR読取を主操作にした初回画面を表示する。ライトを初期値としライト／ダークを明示選択・保存する。

ADR 0010・0019の表示専用WebView、共有通信、音声サービスとADR 0018のネイティブSRTを維持する。画面と配色の変更をサービス開始・停止や資格変更の契機にしない。

タブ移動時の白画面を解消するため、同じActivity内のコメント文書を事前準備して保持する。非選択時はコメント購読と操作・表示を止め、再選択時に同じ文書を表示しながら同期する。カメラは非選択時に従来どおりプレビューを解放する。横フリックはコメント本文などの独立したスクロール面と非操作領域でも受け付け、縦スクロールや操作部品の入力を維持する。条件・再生成・受け入れ条件は所有仕様に記載する。

## 結果

2026-10-13、利用者の追加指示により、スマホ連携の記号をスマホの輪郭へ変更し、「送信・配信」の重複した分類項目を撤去する。送信・配信はヘッダーの電波アイコンから開き、目的別分類は撮影・マイク・品質・画面表示・診断・その他の設定へ絞る。ヘッダーの順序、確認と操作条件は維持する。

2026-10-12、「カメラ設定」と「カメラの操作」の行き先が予測しにくいという指摘から、利用者が目的別の「映像・マイク」の分類一覧を採用した。頻繁に使う「送信・配信」は分類一覧に加え、スマホ連携の左に置く電波アイコンから一操作で開く。カメラ画面の右端は分類一覧の入口とし、コメント画面の設定と読み上げは維持する。分類は操作の所在を整理するものであり、送信・OBS配信・読み上げの独立性と既存の確認・制限を変えない。具体的な配置と受け入れ条件はAndroid画面仕様が所有する。

スマホ連携の説明が長いという追加指摘から、利用者が説明短縮見本の「必要な情報だけ」を採用した。QR・選択・状態を先に置き、通常の詳しい説明は明示展開へ移す。障害の理由と直接接続の登録前の注意は見失わせず、既存の登録・復旧・通信処理を維持する。表示条件は所有仕様に記載する。

プレビューが状態表示のカードで隠れるという追加指摘から、カメラの重畳表示を透明にし、実映像上の文字には影を使う。右上の設定入口は両画面で同じ場所にそろえ、カメラ設定を直接開けるようにする。既存の設定・操作・通信・状態全文は維持する。具体的な表示と入力の契約は所有仕様に置く。

配置・保存・例外・受け入れ条件は[Androidクライアント仕様](../features/android-mobile-client.md#android画面)が所有する。[比較見本](../../prototypes/android-swipe-ui-throwaway/README.md)は参考資料として保持する。従来の共通上部操作・コメント初期表示・紫系固定配色を置き換え、既存設定・診断・権限・安全な確認と登録は維持する。

先行する上部切替の採用元は[ヘッダー・フッター比較見本](../../prototypes/android-compact-chrome-throwaway/README.md)の「切替を上部へ」とする。現行の配置とライト配色の採用元は[フッターなし比較見本](../../prototypes/android-no-footer-throwaway/README.md)の1案「操作を上部に集約」とする。比較見本の架空状態・寸法を通信や診断の契約へ流用しない。
