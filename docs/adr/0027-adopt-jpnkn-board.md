# ADR 0027: 既存の掲示板枠へjpnknを追加する

状態: 採用（2026-10-08）

## 判断

スレッドURLのホストで取得・書き込みアダプターを選択する。保存/API/接続管理は3枠を維持し、共通コメント・AI参加・記憶・ログは実サービス4値を区別する。間隔と次スレッド設定は共用、AI人格/投稿者設定はサービス別とする。

ADR 0005の同名確認・一時状態・自動再送禁止を継承する。ADR 0004/0013の書き込み範囲へjpnknを追加する。認証要求ではブラウザ作成後のURL登録へ案内し、トークン/CAPTCHA処理や登録時の案内POSTは追加しない。読み取りと他サービスは継続する。

## 理由と結果

URL入力だけの使い方と既存3行を保ち、異なるDAT/文字コード/フォームを分離する。接続枠と実サービスを混同するとUI列挙・AI取得所有権・保存検証が壊れるため、型と実行時検証を分離する。旧13/14設定は既存退避/移行規則を維持し追加値を補う。スマホ通信フレームは変えない。
