# したらばへの外部書き込みを次スレッド作成に限定する

追記: 本文は当時の判断を保存する。[ADR 0013](./0013-adopt-ai-listener.md) の採用により、書き込み範囲の限定だけをAIリスナー仕様の投稿へ拡張する。次スレッド作成・URL案内の処理とその他の制約は引き続き本ADRに従う。

v0.2.1では、したらばへの外部書き込みを、現行スレッドを引き継ぐ次スレッド作成と、配信者が任意で有効化する現行スレッドへの次スレッドURL案内に限定する。配信者の操作負担を減らしながら、一般的なコメント投稿や資格情報管理へ機能とリスクを広げないため、公開投稿フォームをサービス別アダプターから利用する。

## Considered Options

- v0.2.0と同じ読取専用連携を維持する方式
- 次スレッド作成とURL案内だけを提供する方式
- したらばへの一般コメント投稿、認証、CAPTCHA処理まで提供する方式

読取専用方式は外部副作用がない一方、配信中に次スレッドを手作業で用意する負担を解消できない。一般投稿まで提供すると、誤投稿、資格情報の保存、投稿規制、重複送信への対処が広がるため採用しない。

## Consequences

- 次スレッド作成の既定はオフとし、配信者が設定した現行スレッドだけを対象にする。
- トリップ、ハンドルパスワード、CAPTCHA、外部投稿禁止など、公開フォームから自動投稿できない掲示板は対象外とする。
- 投稿フォームの項目、文字コード、時刻トークン、成功応答の解析は交換可能なしたらば書き込みアダプターへ閉じ込める。
- 送信後に成否を確認できない要求は自動再試行せず、配信者の確認を待つ。これにより重複スレッドと重複案内を防ぐ。
- 作成、URL案内、読み上げの障害を分離し、コメント取得、他のコメントソース、表示、アプリ全体を停止しない。
- 投稿内容、名前、E-mail、次スレッドURL、外部応答本文をテレメトリー、クラッシュレポート、診断ログへ含めない。
- 外部書き込み操作はループバック管理面だけに提供し、スマホコメント画面を読取専用のまま維持する。

詳細な利用者向け挙動は [したらば次スレッド作成仕様](../features/shitaraba-next-thread.md) を参照する。
