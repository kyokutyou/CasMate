# したらば次スレッドは作成済み記録を永続化せず掲示板の同名タイトルを確認する

次スレッド作成の重複防止は、ローカルの作成済み記録ではなく、作成直前と結果不明時にしたらばの公開スレッド一覧を取得し、作成予定タイトルと完全一致する候補を確認する方式とする。掲示板管理メニューで次スレッドが削除されても過去のローカル記録が残る不整合を避け、再起動後も現在の掲示板を正として判定するためである。

## Consequences

- 作成試行、成功、失敗、結果不明、次スレッドURLは次スレッド一時状態として配信セッション中だけ保持する。
- 自動作成は一時状態ごとに1回だけ試行し、手動操作以外で再試行しない。
- 公開中の同名タイトルが1件ならそのURLを採用し、2件以上なら配信者の確認を待つ。
- 強制終了後は送信中だった事実を復元せず、次回起動時に掲示板を再確認する。
- 設定スキーマバージョン3の作成済み記録はバージョン4への移行時に全件破棄する。
