# 0026: スマホのOBS入力を端末単位で共用する

- 状態: 採用（2026-10-08）。実装と実機検証の完了は別に判定する。
- 更新する判断: ADR 0017の経路別OBS入力、ADR 0018の固定転送先の単位、ADR 0023のスマホ登録対象。

ネットワークごとにOBSメディアソースを作成する手間をなくすため、同じ登録端末には1つの固定ループバックUDP入力を割り当てる。PCが選択中の経路から受信し、同じ入力へ転送する。受信と資格情報は経路別に維持し、端末名を認証・同一性の根拠にしない。

利用者は新しい端末共通ソースを一度登録する移行を選択した。旧ソースを自動変更・削除せず、旧転送ポートの予約を保持する。入力の準備後はネットワークOFFでもOBS登録とコピーを可能にする。

受信管理器を一つに置き換えるだけでは、直接接続の準備と保存の循環待機、端末間の停止待ち、旧ワーカーからの二重転送を防げない。端末別の調停と経路世代、実終了確認を共有し、停止不明を成功扱いしない。認識分岐の接続境界と障害分離も維持する。

PC台帳は版6へ明示移行し、版4・5の既存登録・認識資格・予約を保持する。移行と新しいポート割当を分け、ポート不足を映像だけの障害に限定する。Androidの通信契約とQR登録を変更しない。

正式な動作・保存・入力は[スマホ連携](../features/smartphone-integration.md#device-shared-obs-input)、登録は[OBSソース登録](../features/obs-source-registration.md)、受信・停止・認識分岐は[外配信](../features/outdoor-streaming.md)が所有する。
