# スマホ連携の接続準備を一本化する

- 状態: 契約採用・実装済み（2026-10-04）、v0.5.0。実機検証未完了。確認範囲は[検証記録](../validation/smartphone-unified-preparation-2026-10-04.md)を参照する。
- 正式な動作と確定した更新・互換契約: [スマホ連携仕様](../features/smartphone-integration.md#simplified-preparation)。

ネットワークONに加えて映像ONが必要な構成は、利用者が接続準備の完了を誤認しやすい。さらに、映像OFFで登録したスマホには映像の接続情報がなく、後からONにするとQRの再読取が必要になる。利用者は、ネットワークONで接続準備をまとめ、初回のQR登録後は必要な情報を登録済み端末へ更新し、実際の開始・停止をスマホで行う方針を採用した。

この判断はADR 0017の独立した映像利用設定と、ADR 0020の全機能準備を登録成功の条件にする判断を更新する。独立レビュー後、新招待11／13・応答12／14、更新専用資格と制御版2、新旧要求の明示的な版選択、PC保存4・Android保存5を採用した。利用者は移行時に経路ごと一度QRを読むこと、旧ON・映像OFFを初回だけOFFへ戻すこと、正常な映像を継続して切断時に新候補で復帰することを選択した。機能別状態・失効・保護保存の正式契約は所有仕様に従う。未採用の追加UI案や、登録情報を得られない場所からの無条件の復旧は本判断へ含めない。
