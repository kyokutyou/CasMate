# 過去の互換処理を整理し、契約ごとに対応範囲を管理する

- 状態: 採用（2026-10-04）。実装・実機検証の完了は別に判定する。
- 正式契約: [保存と対応版](../features/local-application.md#compatibility-baseline)、[スマホ登録](../features/smartphone-integration.md#compatibility-reset)、[Android保存](../features/android-mobile-client.md#登録の保存形式)。

開発中に積み重なった旧PC・旧Android・旧設定への対応を一度整理する。現行形式の値・識別子・予約は保持し、既知の対応終了保存は元のバイト列を退避して対象設定を初期化する。未知・破損・復号不能は自動初期化しない。

将来の互換対応を禁止せず、契約ごとの対応版を単一の定義からPC・Androidへ生成する。対応範囲を変更するだけで旧版パーサーが実装されたり古いコードが消える設計にはせず、型・パーサー・退避・コード削除・検証を合わせて更新する。

Androidの登録入口は現行の共通QRへ統一する。現在版のPC台帳にある未登録準備は削除しない。Androidは旧選択を除去した後も他の現行プロフィールを保持し、明示選択まで未選択を許す。現在の完全な版なし送信品質は値を保って保存版1を付与する。

本判断はADR 0012・0017～0021の旧形式互換・旧設定移行の継続判断を更新する。ネイティブ送受信、現在の用途別認証、通常ブラウザ向けLAN/Tailscaleの読取範囲、投稿上限の保存・復旧は維持する。
