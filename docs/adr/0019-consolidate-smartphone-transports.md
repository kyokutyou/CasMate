# ADR 0019: スマホの通信管理をネイティブへ集約する

- 状態: 採用（2026-10-03）

2026-10-04追記: [ADR 0020](./0020-adopt-smartphone-direct-connection.md)で専用HTTPS／WSSとPC鍵確認を追加する。2本のネイティブ接続・購読分離を維持し、直接接続のHTMLと資産も共通ネイティブ通信へ集約する。LAN／Tailscaleの通信版・招待版6・応答版8は維持する。

## 背景

WebViewと音声サービスが同じ履歴を重複取得し、OBS状態とSRT受信証拠はHTTPポーリングしていた。低遅延と切断からの早期復帰を優先し、PCとAndroidを同時更新する。

## 判断

ネイティブSRTは維持する。読取専用データと認証付き制御の2本のWebSocketをAndroidの共有接続管理で所有する。大量の履歴・音声を制御と分離し、用途別資格も分離したまま検証する。コメント表示は既存Web UIを維持し、信頼したPCオリジンのメインフレームだけにメッセージを渡す。音声はM4Aをメモリで先読みする。

単一の全権限接続は公開境界を弱めるため採用しない。全コメントUIのネイティブ再実装は外観・表示設定の重複保守となるため採用しない。ポーリング間隔だけの短縮は要求と接続管理の重複を残すため採用しない。

## 結果

旧Android通信の並行維持を終え、共通QRは版6、登録応答は版8にする。既存の保存値と移行証拠を保持し、必要時は一度QRを読み直す。ロック中に開始済み音声を再生する挙動、明示停止、端末再起動後の自動再生禁止を維持する。正式契約は[PC・スマホ間の通信仕様](../features/smartphone-transport.md)が所有する。
