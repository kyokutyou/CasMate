# 固定の音声認識モデルを初回利用時に取得する

配信者音声認識は、ReazonSpeechで学習された `sherpa-onnx-zipformer-ja-reazonspeech-2024-08-01` のint8構成とSilero VADを固定採用し、インストーラーへ同梱せず、配信者が初めて音声認識セッションを必要とした時にアプリ内から公式配布元より取得する。モデル選択を提供せず再現可能な認識条件を保ちながら、未利用者のインストーラー容量を増やさず、モデル重みをアプリ本体と別に検証・管理するためである。

## Considered Options

- 必要なモデルをWindowsインストーラーへ同梱する方式
- 複数のモデルまたはint8・fp32を同梱し、配信者が選択する方式
- 固定したint8モデルを初回利用時に公式配布元から取得する方式

## Consequences

- 初回利用にはインターネット接続と、ダウンロード、展開、原子的な配置に必要な一時空き容量が必要となる。
- モデル取得の失敗、中断、検証失敗は配信者音声認識だけを利用不可にし、配信者が管理画面から再試行できるようにする。
- 未完了ファイルを利用可能なモデルとして扱わず、採用バージョンごとに配布元、必要ファイル、サイズまたは暗号学的ハッシュを固定して検証する。
- モデルはWindowsの利用者別アプリデータ領域へ保存し、通常のアプリ更新で再取得しない。採用モデルを変更する場合は、設定移行、保存容量、品質比較、利用条件を改めて仕様化する。
- 配布前にモデル重みとSilero VADの利用・ダウンロード条件を公式配布元で確認し、必要なライセンス表示をアプリから確認できるようにする。
- Hotwords、モデル選択、fp32、GPUプロバイダー、認識スレッド数の変更は本決定へ含めない。

詳細なダウンロード状態と復旧動作は [配信者音声認識仕様](../features/streamer-speech-recognition.md) を参照する。
