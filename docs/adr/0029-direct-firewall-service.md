# ADR 0029: 直接接続の受信規則を専用Windowsサービスへ分離する

日付: 2026-10-17

## 背景

直接接続はONでWindows受信規則を作成し、OFFで削除する。操作ごとの短時間昇格ではON→OFF→ONのたびにUACが表示される。利用者から初回だけの許可へ変更する依頼があった。

## 決定

初回にUACで導入する専用サービスが受信規則の管理だけを担当する。通常権限のElectronと短時間ワーカーからローカルIPCで依頼する。管理者専用の実行領域とSID・PC・プログラムの固定、相互プロセス検証、期限・取消・所有照合を必要条件とする。具体的な範囲・失敗・更新・削除は[直接接続仕様](../features/smartphone-direct-connection.md#windowsファイアウォールと閉鎖)が所有する。

従来の常駐昇格禁止はこの限定サービスについて置き換える。アプリ全体の管理者実行、UAC無効化、ファイアウォール無効化、OFF後の許可規則の保持は採用しない。

## 結果

通常の切替ではUACを要求しない。初回導入とサービス更新・修復・削除には管理者の許可が必要で、保護領域・サービス・IPCの維持管理が追加される。自動検証だけで実UACとSCMの動作確認済みとはしない。
