# VOICEVOX試聴のスマホ配信・検証記録

2026-10-02。配信者の依頼により「この声を試聴」をスマホへ配信する変更を行った。追加確認では、PCのコメント読み上げがオンのときだけスマホへ配信する条件を維持すると回答された。正式な条件は [試聴音声の配信](../features/mobile-speech.md#試聴音声の配信) が所有する。

## 変更範囲

- [試聴処理](../../src/main/speech/comment-speech-controller.ts) の合成済みWAVを、[アプリケーション状態](../../src/main/core/app-state.ts) から [スマホ音声](../../src/main/speech/mobile-speech-controller.ts) へ渡した。再合成やPC再生完了待ちを追加していない。
- 試聴要求時の購読と世代を捕捉し、合成中の新規購読・停止再開・端末交代へ古い音声を送らない。スマホでは試聴ごとの専用IDと既存キューを使う。
- [試聴画面](../../src/renderer/components/CommentSpeechPanel.tsx) にスマホへの配信条件を常設し、共通トーストの文言をPCでの試聴完了と明記した。
- コメント読み上げ仕様、スマホ音声仕様、REST一覧を実装前に更新した。Androidのプロトコル・コード・保存形式は変更していない。作業開始時から存在する外配信等の未コミット変更は維持した。
