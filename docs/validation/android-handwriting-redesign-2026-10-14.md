# Android手書き画面の再設計検証（2026-10-14）

正式挙動は [手書き映像合成仕様](../features/android-handwriting-overlay.md#手書きモード)、採用理由は [ADR 0028](../adr/0028-android-handwriting-overlay.md) を参照する。利用者がスマホで操作見本を確認し、全体／中央拡大の交互切替と直接全消去を調整した後、本体への採用を承認した。

## 対象と自動検証

ヘッダーなしのOS安全領域内プレビュー、浮いた上下操作、色／太さパネル、連続ピンチ・移動、遅延描画開始、同セッションの表示位置保持を実装した。送信・GL合成・弱回線時の公開ゲートは既存処理を使用する。

- Android全単体テスト355件、lintDebug（0 errors）、assembleDebug、assembleDebugAndroidTest成功。
- 320／400dp縦、760dp横、ライト／ダーク、文字2倍で操作対象と全領域プレビューを確認。色選択後のペン復帰、太さ選択後の道具保持、パネルの自動閉じ・フォーカス復帰、反映待ち／エラー更新で操作位置が動かないことを確認。
- API 29／35で指の80ms待機・早期移動・スタイラス即時開始、2指への移行、残存指の尾線禁止、メニュー・フォーカス喪失・セッション変更での遅延取消を検証。
- 初回倍率を通常画面の古い寸法で求める失敗を修正し、専用画面の寸法確定後に初期化した。拡大後の操作ボタン起点の混合2指入力が移動へ漏れる失敗を修正し、Composeとネイティブでウィンドウ座標の操作除外領域を共有した。修正後の全単体テストは成功。
- 同じ作業場所で別のAndroidビルドが進行中だったため、同一ソース・同一タスクの出力／キャッシュ／CMake作業先だけを `tmp/android-native-redesign-build` に分離した。Robolectricの既存API 29／35依存キャッシュをSHA-512確認後にコピーし、検査対象の除外やTLS検証の回避は行っていない。
- 映像を隠した場合も全面の黒背景を保ち、固定画像は従来のfit寸法で中央に収める。縦向き出力720×1280・横持ち760×320で比率と枠内表示を検証し、カメラ準備前の編集禁止と準備完了後の線・表示位置保持も確認した。最終修正後に実機7件を再実行して成功した。

## 実機

SH-M15／Android 12、1080×2280、密度480（360dp）のUSB接続端末を使用した。送信サービス停止を確認してデバッグ版を上書きし、登録設定を保持した。

`OutdoorDrawingUiDeviceTest` 2件、`OutdoorDrawingViewportDeviceTest` 1件、`OutdoorDrawingGlDeviceTest` 4件の計7件が成功。画面は320dp相当の縦持ちと横持ち、両テーマ・文字2倍で確認した。全体／中央拡大の交互切替、ピンチによる倍率変化と描画リビジョン不変、色／太さ全項目・直接全消去・取り消し・送信メニューへの到達を確認した。

実GLでは拡大・移動後にタッチ位置の赤い線が送信座標と画面に一致すること、縦横出力・カメラ両向きの変換・端末4方向・プレビュー拡縮で送信／プレビュー画素が一致すること、静止／動画復帰試行／成功・アップロード失敗時の公開版維持を回帰確認した。診断時刻の既存動作は単体テストで回帰確認し、今回の実GLでは未確認。端末の回転設定（自動回転0・回転0）を復元した。

実カメラ・マイクとLAN経由のSRTを専用の受信ホストへ送り、別ポータブルOBSで受信した。`OutdoorDrawingLiveDeviceTest` 1件成功。赤いVの描画、全消去、取り消し後の赤画素数はそれぞれ5228、0、5231（背景0）で、受信映像の変化を確認した。モード開閉・タブ往復後も送信の接続世代が変わらず、映像／音声フレーム数が増え、読み上げサービスが継続することを確認した。音声の聴取や実際の読み上げ発話は今回未確認。

利用者のOBS配信・録画は操作せず、専用OBSも配信・録画を開始していない。検証中の登録は暗号化して退避し、終了時に原本との一致と送信・読み上げ停止を検証した。専用LANホスト／OBSを終了して端末を通常画面へ戻した。

PC側は `pnpm lint`、`pnpm typecheck`、`pnpm test --maxWorkers=2`（147ファイル・1598件）、`pnpm build` が成功した。最初の通常 `pnpm test` は既存の着せ替え画面テストが5秒で時間切れとなり、単独実行で11件成功した。ワーカー数2での次の全体実行は、スマホ画面の検証終了後にWindows一時ディレクトリーの削除がEBUSYとなり1件失敗した。Androidの大きな初回ビルド終了後、その3件を単独で確認し、対象を省かず全体1598件とビルドが成功した。タイムアウト設定・検査対象・テスト内容は変更していない。
