# 配信者音声認識 A案の本体実装検証

2026-09-16。配信者が共通見出しの修正後のA案を採用し、仕様書の更新後に実装するよう依頼した。

正式な画面構成は[管理画面仕様](../features/management-screen.md#配信者音声認識編集画面)、認識・保存・モデル準備の契約は[配信者音声認識仕様](../features/streamer-speech-recognition.md)が所有する。本記録は検証結果であり、正式仕様を重複定義しない。

## 実装範囲

- 共通の `ManagementEditorHeading` に戻る操作・画面名・緑の説明枠を集約し、配信者音声認識と既存コメントフィルターで共用。
- A案の本番利用、マイク準備、明示適用、プレビュー、開閉する調整・履歴・WAV・関連設定・ライセンスを本体へ実装。
- 認証付きのモデル単独準備APIを既存ワーカーの `prepareModel` に接続。
- 通知は共通トーストと「要確認」を利用。処理中のボタンとWAV操作はフォーカスを維持して二重実行を防止。
