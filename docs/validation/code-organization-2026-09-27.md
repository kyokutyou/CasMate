## 変更範囲

- 設定を検証・既定値、移行、ファイル保存へ分離した。[従来の入口](../../src/main/core/settings.ts)は維持し、コメント除外の検証は[機能のモジュール](../../src/main/core/comment-filter.ts)へ集約した。
- 接続アダプターと接続状態を[SourceConnections](../../src/main/sources/source-connections.ts)へ分離した。手動操作とAIリスナーの接続所有権、世代管理、機能間の調整はAppStateに残した。
- ローカルAPIの[Host・Origin・管理トークン検証](../../src/main/server/local-access.ts)、[閲覧用データ](../../src/main/server/local-view-projections.ts)、[スマホ・OBS管理ルート](../../src/main/server/smartphone-management-routes.ts)を分離した。ルートの認証順序とループバック／LANの公開範囲を維持した。
- Dashboardから[取得元操作](../../src/renderer/use-comment-source-actions.ts)と[コメント除外の編集](../../src/renderer/use-comment-filter-editing.ts)を分離した。共通の自動保存・通知・画面構造を維持した。
- 機能仕様の調査入口を更新した。ローカルアプリケーション仕様のスキーマ番号を、既存実装・共有型・AIリスナー仕様に合わせて13へ訂正した。新しいスキーマ移行は追加していない。
- 将来バージョンの設定を上書きしないこと、壊れたJSONの保全、再接続中の停止、取得元の停止失敗の分離について回帰テスト4件を追加した。

正式な契約は[ローカルアプリケーション](../features/local-application.md)、[管理画面](../features/management-screen.md)、[コメント取得](../features/comment-acquisition.md)、[コメント除外](../features/comment-filter.md)などの機能仕様が所有する。本記録は仕様を追加しない。
