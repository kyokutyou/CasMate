# 外配信・音声優先の試験実装検証

対象: 基準コミット `66065a45dc662b7050634e04bc7986e2c75a842d` からのAndroid外配信差分。利用者が暫定値の試験実装を承認。正式な挙動と試験値は[所有仕様](../features/outdoor-streaming.md#実装前の確定項目)に従う。

## 実装した範囲

- H.264／HEVC、固定／自動、独立した音声優先の選択、旧設定の移行、固定と自動範囲の独立保存、プリセット適用。
- 自動低下、GLの現在画像保持、低い目標での復帰試行、回復待ちの延長。計測欠損・再接続で安定時間を持ち越さない。
- カメラ・映像codec・GLの故障を音声経路から分離。映像だけの再準備、実キーフレーム生成による復旧確認、故障世代による遅い成功の無効化。
- 手動非表示・停止を優先し、ライブラリの旧入力へのフォールバックにもカメラ開始禁止を適用。状態更新や長い映像エラーで操作位置を移動しない固定サイズの状態欄。
- QRとPC状態報告の通信形式は変更なし。計測値は端末内のメモリだけで扱う。

## 自動検証

- `pnpm lint`: 成功（250ファイル）。`pnpm typecheck`: 成功。
- Android: `GRADLE_USER_HOME="$env:USERPROFILE/.gradle"` を指定し、`gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:compileDebugKotlin --offline` が成功。25スイート・93件、失敗0件。非Surface入力を模したテスト定数に非推奨警告あり。
- Windows全体: 中断前の `pnpm test -- --maxWorkers=2` は754件成功。再開後の同条件では管理画面の既存テスト5件が時間超過と後続のタイマー不整合で失敗。最終 `pnpm test -- --maxWorkers=1` は86ファイル・754件成功（268秒）。テスト条件・実装の緩和はしていない。原因をAndroid差分やCPU負荷と断定しない。
- `pnpm build`: 最終ビルド成功。NuGetの脆弱性情報取得にNU1900警告あり（取得不能を脆弱性なしとは扱わない）。インストーラー・APKは生成していない。
- Composeの固定状態欄と後続ボタンの座標一致を検証し、`android/app/build/reports/layout/outdoor-adaptation-status.png` を描画・目視確認。長い本文は欄内をスクロールして読む。

設定移行、範囲境界、実際に選択されるcodec、上下方向の寸法、ビットレート上限、固定・音声優先オフ、低下→保持→復帰試行、再悪化、保持失敗の回数上限、切断／計測欠損、手動非表示、GL描画保持、初回画像なし故障での音声非解放、旧入力の再開始禁止、遅い復旧結果を回帰テストの対象とした。GLテストは描画回数の制御を検証するもので、実GPUの画素や時刻を検証するものではない。

## レビュー

仕様軸と規約・故障時影響軸を独立した担当でレビュー。カメラ故障時の全体停止、手動非表示解除時の目標上昇、キーフレーム未確認の成功判定、復旧の多重実行、古い復旧結果による新故障の消去、プレビュー再接続、欠測中の超過時間加算、非表示中の旧カメラ入力再開を修正した。最終の故障時影響レビューに重大な未解決指摘なし。

## 未検証・受け入れ条件

接続済みAndroid実機がないため、Pixel／非Pixel、OBS、30分送信、ロック、回線切替、HEVC相互接続、実GPUの保持画像・向き・時刻、codec／GL再準備中の音声と復号同期は未検証。

判定はローカルの送信待ちと送信カウンターの近似である。SRT再送を含む回線全量、最古音声の正確な待ち時間、OBS側の欠落・遅延を測れていない。500ms窓の映像生成量とセッション中のキーフレーム最大値だけでは回線安定性を実証できない。端末によっては動的ビットレート変更が十分に効かない可能性もある。

したがって**試験実装であり、音声継続性の実証と正式受け入れは未完了**。暫定値の校正と所有仕様の実機試験を完了してから、実運用向けの完了判定を行う。
