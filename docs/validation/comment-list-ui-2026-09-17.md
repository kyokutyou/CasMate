# コメント一覧 A案の本体実装検証

2026-09-17。配信者によるA案「一覧で調整」の採用を受け、正式仕様を先に更新してから実装した。

画面構成の所有文書は[管理画面仕様](../features/management-screen.md#コメント一覧編集画面)。設定とコメント一覧の契約は[コメント一覧仕様](../features/comment-list.md)を参照する。本記録は検証結果であり、正式仕様を重複定義しない。

## 変更範囲

- 共通の `ManagementEditorHeading` にコメント一覧の説明を渡す。
- `CommentListPanel` へ編集領域を分離し、A案の配置、共通スリムスイッチ、方向選択、文字サイズ、RGBA色入力、任意の実コメントプレビューを実装。
- 既存自動保存へ接続。不正な入力を保持し、有効な設定だけを保存・プレビューへ渡す。
- 独立ウィンドウの既存API・実状態と、通常ブラウザ向けURLへ接続。処理中の同一ボタンの二重実行を抑止。
- 成功・操作失敗はDashboardの共通通知へ渡し、保存失敗・入力不正は既存の要確認へ集約。
