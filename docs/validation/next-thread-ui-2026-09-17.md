# したらば次スレッド作成 A案の本体実装検証

2026-09-17。配信者がA案「一覧で整える」を採用したため、[管理画面仕様](../features/management-screen.md#したらば次スレッド作成編集画面)を先に更新してから実装した。機能の契約は[したらば次スレッド作成仕様](../features/shitaraba-next-thread.md)が所有する。

## 変更範囲

- `NextThreadPanel` に編集領域を分離し、A案の縦配置、共通見出し、スリムスイッチ、タイトルと本文の独立選択、任意の投稿者情報を実装。
- 既存の設定保存・作成・結果不明解決APIへ接続。レス番号の範囲と前後関係、不正な投稿者名・案内文を編集状態で保持し、有効値だけを自動保存する。
- 作成予定・URL・状態の領域を固定し、内容更新時は内部スクロールで全文を確認できるようにした。コピー失敗も既存の要確認へ集約する。
- 復旧は明示的な詳細展開とし、検証済みのしたらばURLだけをブラウザー表示・登録へ渡す。作成中や復旧中の重複要求を防ぎ、実行後もフォーカスを保持する。
- 自動保存の保留状態を返す `hasPendingSave` を追加。途中のスナップショットに新しい設定だけが届いても、保存・作成予定更新が完了するまでは手動作成を有効にしない。
- 比較バー、架空状態切替、内部状態表示は本体へ追加していない。バックエンドの作成・案内・切替処理は変更していない。
