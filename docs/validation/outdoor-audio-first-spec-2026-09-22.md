# 外配信の音声優先・送信品質拡張の仕様更新確認

2026-09-22。利用者の「採用します。仕様書を修正してください」に対応した文書変更。正式仕様は[Android外配信](../features/outdoor-streaming.md)、画面は[Androidクライアント](../features/android-mobile-client.md#android画面)、判断理由は[ADR 0015](../adr/0015-adopt-audio-first-outdoor-adaptation.md)が所有する。

## 対象と状態

- 固定／自動ビットレート、H.265、音声優先の現在画像静止、段階復帰、映像故障の分離を正式仕様へ反映した。
- 初回は自動モードでのみ音声優先を利用し、緊急静止中はカメラを継続する。固定での緊急介入・カメラ停止による省電力は将来候補へ残した。
- 初期値・移行は既存動作を維持するH.264・固定・音声優先オフ。制御の閾値・待ち時間・緊急時の目標値等は所有仕様の実装前確定項目へ集約した。
- SPEC、用語、Android画面、対象外一覧、将来候補、ADR 0011との参照を整合させた。2026-09-20の調査ノートには採用後の参照先を追記し、当時の候補記述は経緯として残した。
- 仕様更新済み・実装未完了。今回は文書更新のみの依頼であり、試作・配布物作成・実機検証は実施していない。既存の別件AIリスナー変更は維持した。

## 追加レビュー

担当者による自己レビュー。独立レビュー・実機試験ではない。

1. **要求・仕様との一致**: 現在画像を未圧縮で保持して新しい時刻で再エンコードすること、同一SRT、低目標値との組み合わせ、段階回復、手動非表示優先、固定での緊急介入を初回範囲から外すことを確認。旧「H.264限定」「送信中品質固定」「自動変更なし」を必要な範囲だけ更新し、互換QR・PC状態報告を維持した。
2. **故障時・影響範囲**: 音声を含む全キャッシュ消去の混雑対策への流用を禁止し、カメラと映像codecの故障を分離。保持画像取得失敗、静止中の見かけ上の安定、再接続、遅い復帰処理、マイク喪失・手動ミュート・明示停止・OS制約を確認。カメラ調整の既存説明に緊急静止の例外を明記し、音声送信中の映像局所故障で全体を停止状態にしないことを補った。
