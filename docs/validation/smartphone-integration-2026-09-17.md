# スマホ連携の用途選択とAndroid登録画面の統合

2026-09-17。利用者が「用途を選ぶ構成」と「PC・Androidの登録・設定画面を両方整理」を採用した変更。

## 対象

- PCのホーム・設定一覧を「スマホ連携」へ統合。初回は用途選択だけを表示し、コメント利用または映像もOBSへ送る用途へ進む。
- 用途往復と他画面への移動で入力・選んだ手順を保持。警告は共通入口へ集約し、該当用途へ案内する。用途切替を保存・公開・開始の契機にしない。
- 映像用途はOBS接続、接続準備、OBS受信設定、スマホ登録、開始操作の順。コメントの公開準備と読み上げ利用可否を区別する。
- Androidのコメント画面と外配信設定から同じ「スマホ連携」を開く。QRを主操作とし、コメントURLの手入力は任意展開。登録済み機能・OBS操作経路・結果を同画面で確認できる。
- QR解析・保存処理の入口をMainActivityへ集約。既存QR版1〜4・コメントURL、暗号化保存と各機能の開始停止の独立性を維持する。
