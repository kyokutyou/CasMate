## 表示・操作確認

本体コンポーネントを使うローカル確認画面 `tmp/obs-production-preview/` で接続処理を模擬して確認した。

- 幅320・560・760pxの各手順で、主要な入力・ボタン・説明が横にはみ出さない。
- 幅320pxで登録QRと説明・閉じるボタンが画面内に収まることを画像で確認。
- 長い保存エラーでも準備ボタンの位置・寸法・スクロール位置を維持し、共通警告にも表示される。
- 状態報告の確認時刻を追加しても、固定領域に収まり入力位置が変わらない。
- 旧OBS入力の案内を常設の折りたたみに変更。最終確認で準備前・処理中・成功後のスクロール領域高がすべて2128pxで一致し、成功後も準備ボタンにフォーカスを保持。
- 入力フォーマットの `mpegts` が文中に表示されること、指定の配信開始説明文が表示されることを確認。
- 登録QRを閉じると登録ボタンへフォーカスが戻る。検証後に画面幅の上書きを解除した。

独立した仕様レビューと実装基準レビューを実施。後者で指摘された状態表示による位置ずれを修正し、再レビューで解消を確認した。
