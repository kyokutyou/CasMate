## ブラウザー確認と限界

本番の `ManagementShell` と `CommentSpeechPanel`、共通CSSをそのまま使う一時ハーネスをローカルで起動し、設定・一覧・試聴のAPIだけをメモリ内の検証用処理へ差し替えて確認した。検証用タブとサーバーは終了した。

- 実測CSS幅1024・760・560・320pxで横はみ出しなし。760×560pxでも4列のミキサーと下部2列を維持し、560pxでは下部1列、320pxではミキサー2列になる。
- 縦スライダーの実測高さ150px。上矢印で値が増え、下矢印で減り、数値入力と現在値表示に反映される。
- 範囲外入力はエラーを表示して試聴を無効にし、有効値へ直すと試聴できる。試聴後も読み上げオフを維持する。
- 下部の読み上げ内容・VOICEVOX操作は常時表示される。ブラウザーの警告・エラーログなし。

実際のVOICEVOXによる音声再生、実機のWindows出力、Electron外枠と表示倍率を組み合わせた確認は今回実施していない。APIへの接続順序・失敗処理は自動テストで確認した。
