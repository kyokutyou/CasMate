# ネットワーク別スマホ連携・複数端末の検証

2026-10-03。対象は [スマホ連携仕様](../features/smartphone-integration.md) と [ADR 0017](../adr/0017-network-based-multi-device-smartphone-integration.md) のPC・Android実装。レビュー時の基準コミットは `3a27c6dc913d0fb91a0ad8f91a7ec119102a4b15`。本記録は当該作業ツリーの変更を対象とし、配布版の受け入れ完了は示さない。

## 実施した変更と確認範囲

- LAN／Tailscaleの排他的な選択、両方OFF、経路別の映像設定、コメント提供の常時有効化を一つの管理状態へ統合した。ネットワーク切替と保存を直列化し、待受失敗で別経路を復活させない。
- 端末台帳、用途別認証、端末・経路別のOBS受信UDPポート、削除済みポートの予約、複数音声クライアントと端末別のキュー・停止を実装した。OBS操作の確認所有者も端末別に検証する。
- QR版5とAndroidの両経路保存・共通選択を実装した。旧登録の移行、同一性不明時の拒否と案内、非選択側の更新時の通信維持、保存失敗時の既存登録保持を検証した。
- ネットワークのOFF・切替・削除はPCの登録と待受へ適用する。AndroidからOBSへの保存済みSRT送信を止める機能は追加していない。
- 正式仕様の所有文書と参照先を更新した。変更した11文書のローカルリンク321件・アンカーを確認し、欠落なし。過去の検証記録は当時の記録として保持した。

## 画面確認

- Electronで本番部品のSSRと本番CSSを読み込み、320・560・760px幅で、処理中・長文・成功・消去の計12パターンを確認した。状態欄と共通通知のDOMを更新しても、入力位置・本文高・スクロール・フォーカスが変わらず、横はみ出しがない。ネットワーク選択ボタンの見出し・補足文字のコントラストも検証した。
- 撮影結果を目視し、共通ボタンCSSによる補足文字のコントラスト不足を修正した。画像は作業用の `tmp/smartphone-layout/320.png`、`560.png`、`760.png`。
- Codex内ブラウザの1280×720px画面で、本番の `ManagementShell` と `SmartphonePanel` を仮の接続情報・保存処理に接続して操作した。表示だけの切替では公開選択を変えないこと、TailscaleをONにするとLANがOFFになること、経路別映像設定、不正ポートで登録操作を抑止すること、画面往復後の入力保持、正常値の自動保存、登録QRの表示、Esc後と戻る操作後のフォーカス復帰を確認した。利用者の保存設定・端末・OBSへは接続していない。
- Androidの登録画面のComposeテストと描画結果を確認した。これを実カメラ・音声出力・OBS受信の確認とは扱わない。
