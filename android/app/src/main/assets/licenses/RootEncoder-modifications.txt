CasMate modifies the common, srt, encoder and library source modules:
- Numeric transport snapshots with ACK, expiry, queue and frame progress.
- Explicit video bitrate API results (not running, accepted, error).
- GL submission and encoder timestamp correlation for live frame evidence.
- MPEG-TS PCR aligned with PES presentation timestamps instead of device uptime.
The original APIs are retained. Source provenance and changes are documented
in android/vendor/rootencoder/UPSTREAM.md. The full license accompanies this notice.
