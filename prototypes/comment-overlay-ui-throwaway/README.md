プロジェクトルートで次を実行する。既存のViteとReactを使用し、追加の依存関係は不要。

```powershell
node node_modules/vite/bin/vite.js --config prototypes/comment-overlay-ui-throwaway/vite.config.mts
```

## 設計の見直し

- 共通の戻るボタン・画面名・緑の説明枠から、直接設定へ進む。現在値の要約を入力の直前に繰り返さない。
- 表示方法を説明付きの2択にし、選択した方法に関係する表示時間・方向だけを提示する。非表示になった設定値は保持する。
- 表示する情報を用途の説明付きスイッチにする。最後の1項目はオフにできない。
- 文字色・背景色はカラーピッカーと不透明度に分ける。余白と角丸は任意に展開する。
- 外観がOBS音声認識ビューにも共用されることを外観設定の近くで知らせる。
- プレビューとOBS追加案内は明示操作で開く。プレビューは静止した架空コメントで、実際の表示時間・読み上げ同期を再現するものではない。
- 共通のManagementEditorHeading・SlimSwitch・ManagementWarningsと管理画面CSSを再利用。成功通知は既存ヘッダートーストの表示・寿命に合わせたメモリ内の見本。

## 比較できる操作と制約

表示方法、方向、表示時間、3つの表示項目、フォント、文字サイズ、色、不透明度、余白、角丸を操作できる。「比較用の操作」で読み上げ中・保存失敗・長文通知を確認できる。入力と反映済み設定は内部状態の開閉欄で比較できる。

数値・色は500msの模擬反映、選択・スイッチは即時の模擬反映。範囲外の値は反映せず入力を保持する。保存失敗からの復旧は、失敗状態をオフにした後に値を変更して確認する。

バックエンド、実ファイル、OBS、クリップボードには接続しない。フォント一覧とURLは固定見本。ホーム・設定は戻り先を確認する最小限の見本で、実際のホーム全体やPC計測は再現しない。比較コードを製品へそのままコピーしない。比較時点の検証記録と採用後の実装は区別する。
