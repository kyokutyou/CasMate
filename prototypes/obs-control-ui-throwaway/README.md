# OBS操作の設定UI：3案比較

2026-09-17作成。同日、配信者がB案とスマホ登録・自動保存の改善を採用。本体には改善後のUIを実装した。このディレクトリは選定時の3案比較を保存しており、適用ボタン・登録チェック項目を含む旧見本である。現在の挙動は[OBS操作仕様](../../docs/features/obs-control.md)、実装の検証状況は[検証記録](../../docs/validation/obs-control-settings-2026-09-17.md)を参照する。

```powershell
node node_modules/vite/bin/vite.js --config prototypes/obs-control-ui-throwaway/vite.config.mts
```

http://127.0.0.1:5201/?variant=A を開く。下部のA/B/C・左右ボタン、入力中以外の左右キーで比較する。各案を `?variant=A`、`?variant=B`、`?variant=C` で直接開ける。この環境では `pnpm exec vite` が実行ファイルを解決できなかったため、同じローカルViteをnodeで起動する。

| 案 | 狙い | 構成 | トレードオフ |
| --- | --- | --- | --- |
| A 一覧で整える | 設定全体を見渡す | 接続、音声、Androidの3領域を縦に並べる | スクロールが長い |
| B 目的で切り替える | 小さいウィンドウで必要な設定に集中 | 接続・音声・Androidのタブ | 別領域の確認にはタブ移動が必要 |
| C 手順に沿って整える | 初回準備の順序を理解 | 番号付きの開閉領域と次への案内 | 慣れた後は開閉操作が増える |

採用はB。日常の変更対象を切り分けやすく、限られた高さで編集できる。本体では目的別の接続案内と自動保存を組み合わせる。

## 見直した点

- 接続設定、音声操作、Android登録を用途ごとに整理。
- 音声フレーズを開始・終了別に「指示→別の発話で確認」の組として表示。
- 設定のオン・オフ、OBS接続、OBS配信、確認待ちを別の意味として表示。
- オン・オフの即時保存と、その他の項目の「この設定を適用」を区別。
- 適用ボタンを1つに集約し、未適用値は案・タブ・ページ移動をまたいで保持。
- QRを明示操作で開くダイアログへ移動。結果不明は再送操作を追加せず説明。

## 見本の境界

既存の比較見本と同じく独立ディレクトリへ隔離し、本体の入口・APIへ接続しない。設定や秘密の保存、OBS接続・配信操作、実際の公開待受・登録・QR発行は行わない。初期表示の「パスワード設定済み」は架空の例で、実データを参照していない。QRは読み取りできない明示的なプレースホルダー。

確認待ち10秒、取消、接続失敗、操作結果不明、登録の再生成・無効化は配置評価用の模擬動作。OBSプロトコル・認証・全状態機械を再実装したものではない。Android登録は表示例で、実端末の確認成功を意味しない。下部の「状態の見本・内部状態を確認」で表示例を切り替えられる。パスワードは内部状態表示でも伏せる。
