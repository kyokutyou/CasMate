## 見本の境界

既存の試作と同様に独立ディレクトリへ隔離。本体の入口へ接続せず、ブランチ切替・コミットは行っていない。

設定はメモリ内だけに保持し、案・タブ・ページ移動をまたいで共有する。リロードで初期化する。投稿、クリップボード、ブラウザ表示、設定保存、接続、レス番号による自動実行は模擬であり、外部サービスや実データを操作しない。現行スレッド・最大レス番号・タイトル・本文・URLは架空の例。

画面下部の比較用操作で作成待ち・作成中・作成済み・結果不明・失敗・入力が必要な状態を確認できる。実サービスの全状態機械の再実装ではなく、レイアウト判断用の表示例。結果不明では明示的に復旧領域を開き、同じ架空掲示板の作成済みURL登録または未作成確認を試せる。内部状態は比較用操作の詳細で表示する。
