# 配信中の画面：操作できる比較見本

**破棄可能な試作。正式仕様・製品実装ではありません。**

比較する問い：コメントを読みながら、読み上げ・AIリスナー・音声認識へスクロールせずに手が届く配置はどれか。

製品のオーシャン／パール配色とSlimSwitchを使用し、既存のブランド・4ページのナビゲーションを再現します。このディレクトリは比較資料として独立しており、製品の起動・ビルドには含みません。

## 起動

リポジトリのルートで1コマンド：

```powershell
pnpm exec vite --config prototypes/live-screen-ui-throwaway/vite.config.mts
```

[A：操作を上部に集約](http://127.0.0.1:5207/?variant=A)／[B：操作を左に常設](http://127.0.0.1:5207/?variant=B)／[C：コメントを広く、操作は下へ](http://127.0.0.1:5207/?variant=C)

下部の比較操作から配置・幅・配色・状態を変更します。左右矢印キーでも案を切り替えられます。入力・ボタンの操作中やダイアログ内では横取りしません。

2026-10-15、配信者の選択によりA案を採用し、上部の操作順を「読み上げ → 音声認識 → AIリスナー」として本体へ反映しました。正式な挙動は[管理画面仕様](../../docs/features/management-screen.md#配信中)が所有します。B・C案は比較資料として配置を維持しています。

## 試せる操作

- 読み上げ・AI・音声認識の切替、各状態・設定への入口。
- 架空の新着コメントの連続受信と1件追加、読み返し中の追従停止、最新への復帰。
- 取得ソース別の開始・停止と接続エラーの復旧。
- AI確認待ちの理由確認と明示再開。OBS停止時の配信待ち。
- 認識プレビューの個別開始・停止、独立ウィンドウの模擬表示状態。
- 通常／接続エラー／AI確認待ち／初回未接続、320～1200px、ライト／ダーク。
- 「見本の状態」で全状態ペイロードを閲覧。

全操作はタブのメモリ内だけに反映します。案の切替で状態と読み返し位置を保持し、再読み込みで初期化します。実API・音声・カメラ・AI生成・OBS制御・外部通信・永続化はありません。OBSとスマホの状態は架空値です。ほかの主画面・詳細設定は入口確認だけで、製品の全設定を複製しません。
