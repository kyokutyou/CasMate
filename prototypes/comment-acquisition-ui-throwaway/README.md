# コメント取得 UI・UX 比較見本

2026-09-16。既存のホーム／設定の枠内でコメント取得の編集領域を再構築した、破棄可能な比較用プロトタイプ。同日、利用者がA案を採用した。本体への反映・検証は [実装検証記録](../../docs/validation/comment-acquisition-ui-2026-09-16.md)、正式仕様は [管理画面仕様](../../docs/features/comment-acquisition.md#管理画面) を参照する。以下の見本の模擬動作は正式仕様ではない。

```powershell
node node_modules/vite/bin/vite.js --config prototypes/comment-acquisition-ui-throwaway/vite.config.mts
```

http://127.0.0.1:5194/ を開く。`?variant=A`、`?variant=B`、`?variant=C` でも指定できる。画面下の案選択と左右の矢印で比較する。入力・選択中の矢印キーは通常の編集操作を維持する。

| 案 | 操作の構成 | 向いている使い方 | トレードオフ |
| --- | --- | --- | --- |
| A：接続リスト（推奨） | コメントソース・接続先・状態・スイッチを行単位で対応付ける | 毎回の配信準備、複数の接続先の確認 | 狭い画面では縦に長くなる |
| B：ソース別ワークスペース | 状態一覧で選択し、1つの接続先を大きく編集する | 説明を読みながら設定、1件の問題を調査 | 複数の接続先の比較には切替が必要 |
| C：順番に準備 | 接続先、自動接続、接続確認の3段階 | 初回設定、操作順が分からない場合 | 日常的な調整には移動が増える |

## 比較の範囲

- 入力値は案切替・コメントソース切替・ホーム／設定への移動で維持する。
- 個別スイッチ、一括開始・停止、再接続、自動接続、したらばの取得間隔を操作できる。
- 通常、初回設定、接続中、自動再接続、入力エラー、保存失敗を比較用選択肢で再現する。
- 入力の反映、接続処理、成功通知は模擬動作。外部通信、実際の保存、コメント取得、テレメトリーはない。更新すると初期値へ戻る。
- 待機・接続・停止を文字と記号で区別する。警告は要確認へ集約し、入力欄の説明は予約済み領域内で更新する。成功通知は既存の72pxヘッダー内で4秒表示する。
- 状態JSONは比較・検証専用。本体への搭載対象ではない。

同じ `fragment.html` を会話内とローカルプレビューで使用する。本番のエントリーポイントから参照しない。採用前の比較資料として独立ディレクトリに置き、ブランチ切替やコミットは行っていない。

## 正式仕様との関係

機能契約は [コメント取得仕様](../../docs/features/comment-acquisition.md)、画面構成・通知は [管理画面仕様](../../docs/features/management-screen.md)、保存は [ローカルアプリケーション仕様](../../docs/features/local-application.md#設定保存)、用語は [CONTEXT.md](../../CONTEXT.md) を参照する。

A案の画面構成は所有文書である管理画面仕様へ記録し、本体の設定保存・接続処理へ実装した。比較用コードは製品から参照しない。

- `node prototypes/comment-acquisition-ui-throwaway/verify.mjs`：3案、入力保持、6状態、範囲検証、障害分離、一括操作、保存再試行、警告からのフォーカス、通知寿命、HTML内スクリプトのlintを確認。

- `pnpm typecheck`：成功。
- `pnpm test`：58ファイル、542テスト成功。
- `pnpm lint`：既存の不正なディレクトリエントリーに対するENOENTで停止。`node node_modules/eslint/bin/eslint.js src tests prototypes/comment-acquisition-ui-throwaway` は成功。

- インストーラー、展開版EXE等の配布物は生成していない。
