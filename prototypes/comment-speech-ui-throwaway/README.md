http://127.0.0.1:5193/ を開く。`?variant=A` ～ `?variant=E` で直接指定できる。

| 案 | 構成 | 想定する使い方 | トレードオフ |
| --- | --- | --- | --- |
| A | 一覧で調整 | 声と読み上げ内容を同時に見ながら変更 | 狭い画面では縦に長くなる |
| B | 目的別タブ | 声・内容・接続を分けて編集 | 別の分類の値は切替が必要 |
| C | 要約から展開 | 普段は現在値だけ確認し、必要な箇所を開く | 初めての利用では項目の発見が一段深い |
| D | 音声ミキサー | 音量・話速・音高・抑揚を頻繁に調整 | 音声調整が主役になり、内容設定は下へ移る |
| E | 順番に設定 | 接続→声→内容の順で準備する | 慣れた後の横断的な変更には移動が増える |

全案で設定値を共有し、比較時に入力を失わない。起動状態・保存エラー・話者未選択などを比較用コントロールで再現できる。
設定変更はメモリ内だけ。試聴・エンジン選択は説明付きの模擬操作で、音声再生・外部通信・本番保存は行わない。
状態JSONは見本の検証用であり製品の表示内容ではない。
