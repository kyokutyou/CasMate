# スマホ連携・配信者音声認識の比較見本（throwaway）

2026-10-21、A案「手順と確認を並べる」を採用。本ディレクトリは比較資料として保持する。現在の配置・操作・保存の契約は[初回設定仕様](../../docs/features/initial-setup.md#案内と確認)に従う。模擬操作・架空データ・比較バーを本体へ移植しない。

はじめての設定の既存C案の枠・配色で、残る2画面の案内方法を比較する。
製品コード・正式仕様の変更は含まない。実接続・録音・モデル取得・設定保存なし。

起動（リポジトリルート）：

```powershell
pnpm exec vite --config prototypes/initial-setup-phone-recognition-throwaway/vite.config.mts
```

http://127.0.0.1:5233/?variant=A&screen=phone

- A：手順と確認を並べる。全手順を見渡し、右側で結果を確認。
- B：1つずつ案内する。今の操作だけを表示し、手順ごとに進む。
- C：準備状況から進める。未完了項目を案内し、必要な操作を選んで開く。

下部の比較バー・左右矢印で案を切替。入力中は矢印キーを奪わない。
`screen=phone|recognition`。状態はメモリのみ、案・画面の切替では保持し、再読込で初期化。
「状態・場面」で全状態JSONと、未準備・登録済未接続・確認済・入力エラーの場面を表示。
比較バーは開発サーバーのみ。製品ビルドから独立したパスに置く。

確認する点：登録と接続の違い／用途に応じた確認／未適用の入力と適用済み入力の区別／
プレビューと配信に使うONの分離／狭幅での操作と確認順序。
モデル容量などは現在の機能仕様・既存画面を基に表示。QRと認識結果は使用不能な説明用見本。
