# Androidきゃすメイト 下部操作案の見本

2026-10-07作成。4案からユーザーが選択した「A 下部に操作」だけを表示する。カメラ・コメント画面のフリック説明欄と、読み上げなど通常操作後の下部説明欄を削除し、空の説明領域も残さない。左右フリック、下部タブ、通信断・権限拒否・確認失効の表示は維持する。この見本は比較資料として保持する。2026-10-07に採用し、Android本体の現行動作は[正式仕様](../../docs/features/android-mobile-client.md#android画面)と[ADR 0024](../../docs/adr/0024-adopt-android-camera-comments-ui.md)を参照する。

初回起動の提案として、未登録時だけ「PCとつなぐ」画面を表示する。主操作「PCのQRコードを読み取る」で共通QR読取へ直接進む。「QRコードの表示場所」でPC版の設定→スマホ連携→利用ネットワークON→共通QRの手順を確認できる。未登録時はカメラ・コメント操作へ移動せず、登録成功後に下部操作案のカメラ画面へ進む。登録だけで送信・OBS配信・読み上げを開始しない。初回起動を初期表示にし、登録済みの状態は場面選択で確認する。この手順は見本で提案した後、2026-10-07に正式仕様へ採用した。見本の登録は引き続き模擬操作とする。

配色はライト／ダークを明示選択でき、初期値は採用済みのライト配色。登録後のカメラ・コメント設定の先頭「配色」で選択し、初回登録画面では右上の月／太陽アイコンで切り替える。ダークは深い緑の背景と明るい文字を使用する。選択は画面移動・模擬登録・場面変更後も維持し、チャット内の見本状態復元にも含める。見本の操作状態のみで、製品設定へは保存しない。

## 共通の操作

カメラ画面では映像・マイク送信、マイクミュート、映像を隠す、プレビュー、確認付きOBS操作、カメラ・送信設定を模擬する。コメント画面ではコメント閲覧、最新への追従、読み上げを模擬する。左右フリックは機能画面の切替だけを行い、送信・OBS本番配信・読み上げの状態を変更しない。画面内の切替ボタンと、画面へフォーカスを置いた状態での左右矢印キーでも移動できる。

ボタン、入力、設定ダイアログの操作、縦方向のスクロール、短い移動、複数指の操作は画面フリックとして扱わない。確認中のOBS操作は画面を離れたときに取り消す。「配信中」「開始前」「通信断」「初回起動」の表示例は見本全体に適用できる。

映像・マイク送信、OBS本番配信、読み上げは独立した状態として扱う。送信停止とOBS操作は確認後だけ変更し、OBS確認は10秒で失効する。登録・画面移動だけではサービスを開始しない。送信中の経路変更・QR登録は無効。QRは架空の登録手順を示すプレースホルダー。

## 見本の境界

実際のPC・OBS・カメラ・マイク・読み上げ・Androidサービスへ接続しない。製品の登録・秘密・コメント・設定を読み出し・保存せず、外部ネットワーク通信を行わない。表示内容と数値は架空の例。チャット内では見本の操作状態だけを復元する場合がある。プレビューには外部通信を許可しないCSPを適用し、CDNや依存パッケージを追加しない。

正式な製品動作は[Androidクライアント仕様](../../docs/features/android-mobile-client.md)、[通信仕様](../../docs/features/smartphone-transport.md)、[外配信仕様](../../docs/features/outdoor-streaming.md)、[OBS操作仕様](../../docs/features/obs-control.md)、[直接接続仕様](../../docs/features/smartphone-direct-connection.md)が所有する。ネイティブ／WebView分離とネイティブ音声サービスを維持する。この比較見本の成功をAndroid実機・OBS実接続・実回線の確認成功として扱わない。配布物は生成しない。

`verify.mjs`はJSDOMで画面分離、左右切替、誤操作の除外、画面外の指離し・取消とフォーカス喪失後の復帰、切替前後のサービス状態保持と確認取消を確認し、前回見本の登録・接続・確認期限・設定・ダイアログ・障害時表示の回帰検証も行う。画面サイズ・文字拡大・実機のタッチ操作はJSDOMの対象外。描画・操作領域は `verify-layout.mjs` で別に確認する。

製品の通常の完了確認は `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build`。製品ソースや正式仕様をこの試作で置き換えない。
