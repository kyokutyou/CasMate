# 手書き画面の操作見本

「ヘッダーも映像に使う手書き画面の再設計」を試す独立した見本。2026-10-14に利用者が採用を承認し、[正式仕様](../../docs/features/android-handwriting-overlay.md) を更新した。本体への組み込み後も、この見本は製品へ接続せず配置や操作の確認用に残す。

```powershell
node node_modules/vite/bin/vite.js build --config prototypes/android-drawing-throwaway/vite.config.mts
node node_modules/vite/bin/vite.js preview --config prototypes/android-drawing-throwaway/vite.config.mts
```

<http://127.0.0.1:5212/> を開く。端末相当の画面サイズ・配色・文字サイズ・状態は、電話の外側の選択欄で変更する。`?device=1` は見本の周辺説明を隠す。

- 1本指／マウスで描画。スタイラスは即時描画、指は最大80ms待ち、8 CSS px以上の移動で先に開始する。Android移植時は端末のタッチ判定距離へ置き換える。
- 2本指で拡大・移動。PCではホイールで拡大、Spaceを押しながらドラッグで移動。
- 下の6操作はペン、消しゴム、色・太さ、取り消し、全体／中央拡大、全消去。説明は長押しとアクセシブル名で確認する。
- 色／太さを選ぶとパネルが閉じる。右端のゴミ箱アイコンを1回押すと全消去し、元に戻せる。
- 初回は中央を拡大表示する。全体ボタンは、1倍・中央の全体表示と、中央を表示領域いっぱいに広げる表示を、押すたびに交互に切り替える。初回の押下は全体表示。中央拡大の倍率はその時の表示領域から1〜6倍で求める。手動の拡大・移動ではボタンの順番を変えず、閉じて「手書きに戻る」を押すと倍率・位置・線・次の切り替え先を保持する。
- 反映待ちでは送信版を固定する。閉じると固定版が全体表示され、再開すると編集版へ戻る。通常へ変更した時だけ編集版を反映する。
- エラーの再試行は直前の状態へ戻す。反映待ちからのエラーでは、再試行しても下書きを公開しない。

架空の静止映像・ローカルのメモリーだけを使う。カメラ、マイク、SRT、OBS、設定保存、外部サービス、テレメトリーは利用しない。ローカルのVite previewは見本ファイルだけを配信し、HMRの通信も行わない。製品ビルドには入らない。

## 検証

```powershell
pnpm lint:prototypes
pnpm test:prototypes
node node_modules/vite/bin/vite.js build --config prototypes/android-drawing-throwaway/vite.config.mts
```

`verify-layout.mjs` はビルド済みHTMLと出力ディレクトリーを絶対パスで受け取る。第3引数に `--live` を加えると、起動済みのローカル表示URLを検証する。Electronはプロジェクト直下でなく、検証専用の絶対パスの一時ディレクトリーを作業場所にして起動する。320／400縦・760横、ライト／ダーク、文字標準／2倍、状態更新と入力競合を自動確認する。

2026-10-14、SH-M15（Android 12）のChromeで見本の実機確認を実施した。USB経由のタップ・スワイプで全体／中央拡大の交互切り替え、色選択、描画、全消去と取り消し、部分消去、モード開閉後の保持、縦横配置を確認。利用者が許可した一時デバッグ接続で2本指の拡大・移動を確認し、誤描画・全指解除後の不要な線がないことと全体／中央拡大への復帰を検証した。デバッグ転送は解除し、端末の回転設定を復元した。

上記はブラウザーのCanvasによる操作見本の確認。本体へ反映した後のネイティブ入力・実GL・SRT／OBSの結果と未確認範囲は [本体の検証記録](../../docs/validation/android-handwriting-redesign-2026-10-14.md) を参照する。実際の手指・スタイラスによる操作感の評価は未実施。
