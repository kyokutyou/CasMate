# 確認する問い

ヘッダーをなくして映像の上に操作を浮かせ、1本指で書く／2本指で表示を動かす画面は、縦持ちでも書き込みやすいか。

## 今回の見本

利用者が選んだ浮いた道具列の1案を作る。OS安全領域は残し、プレビューがアプリ部分全体を占める。上の閉じる・送信、下の6個の道具は固定位置とし、通知で動かさない。色・太さは下部パネルへ置く。送信枠の1280×720は変えず、見本表示だけを拡大する。

道具・状態の確認用選択欄・内部状態は電話の外側に置き、実際の画面へ開発用表示を入れない。操作が映像の一部を覆う点、拡大すると送信枠の端が隠れる点、細かく書くときの2本指切り替えを確認する。

## 採用の状態

利用者の見本確認後の調整として、全体ボタンに「1倍・中央の全体表示」と「中央を表示領域いっぱいに広げる表示」の交互切り替えを追加した。初回は拡大表示なので最初の押下で全体表示へ戻す。送信枠や描画内容は変えない。

追加の調整として、右端の「その他」をゴミ箱アイコンの全消去ボタンへ置き換えた。1回の押下で消去でき、取り消しを維持する。

2026-10-14、利用者が操作見本を採用し、Android本体への実装を承認した。正式仕様は [手書き映像合成](../../docs/features/android-handwriting-overlay.md) を参照する。

カメラ／コメントの通常ヘッダー、既存の送信セッション・弱回線・実GL合成契約を保ったまま本体へ反映する。見本は正式仕様の代わりにしない。
