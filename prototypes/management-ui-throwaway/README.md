# 管理画面UI比較（破棄可能な試作）

PC管理画面の設定の探しやすさを、元の3案、Cを基準にした6案、Aを基準にした縦長3案、A改良案、元のAから見直した3案の計16案で比較する。正式仕様でも本体実装でもない。

## 起動

リポジトリのルートで実行：

```powershell
node node_modules/vite/bin/vite.js --config prototypes/management-ui-throwaway/vite.config.mts
```

[比較画面](http://127.0.0.1:5190/?variant=A5) を開く。下部の「Aを見直す3案」で最新の3案を切り替える。元の比較グループも保持。左右矢印ボタン・キーは全16案を順に巡回する。入力中やダイアログ内では矢印キーを横取りしない。

## 元のAから見直す3案（A5〜A7）

### A5のPC状態表示を比較する

ホーム最上部の既存ヘッダーで、ロゴ右側にコンパクトな数値表示を置く。ヘッダーの高さを増やさず本文の領域を確保する。下部の「PC表示」1〜3で切り替え、URLの `pc` に反映する。全案で同じ架空値を共用し、実測・外部送信・グラフ表示は行わない。

採用案はPC表示3「数値を主役に」。A5で `pc` が未指定または不正な場合も3を初期表示する。比較用の1・2は残す。GPU・VRAM・メモリは間隔を詰めて右端にまとめる。ヘッダー内では折り返さず、420px以下ではブランドをアイコンだけにして数値の領域を確保する。本体への反映はまだ行わない。

- [1：テキスト行](http://127.0.0.1:5190/?variant=A5&pc=1)：文章に近い横並び。余白を最小限にする。
- [2：細いステータスバー](http://127.0.0.1:5190/?variant=A5&pc=2)：低い帯で、操作できる領域を示す。
- [3：数値を主役に](http://127.0.0.1:5190/?variant=A5&pc=3)：ラベルの下に数値を並べ、横一列で読み取りやすくする。

クリック・Enter・Spaceで共通のPC状態ダイアログを開く。GPU使用率、GPUメモリ使用量／総容量、PC全体の使用メモリ量／総容量、きゃすメイトのCPU使用率・使用メモリ量を表示する。アプリ負荷は関連プロセスを含めた表示例とし、取得方式は未決定。

ダイアログ下部で「通常・高め・高負荷」を切り替えられる。PC全体の各数値は使用率80%未満を緑、80%以上を橙、95%以上を赤にする。VRAM・メモリは総容量比で判定し、最も高い状態を小さな丸印で示す。背景は固定。これは比較用の仮の閾値で、実機の異常判定ではない。案の切替で状態を保持し、初期化で通常に戻す。

現在の検討ベースは **A5**、スイッチは **スリム** に決定。A5を調整していく段階で、本体への移植はまだ行わない。

A5の設定編集画面の戻り先は、開いた場所に合わせる。ホームから開くと「ホームに戻る」、設定一覧から開くと「設定に戻る」と表示する。戻る際は本文のスクロール位置と押した入口ボタンへのフォーカスを復元し、編集値を保持する。

A5の各コメントソース名は接続設定への入口とし、押すと共通の「コメント取得」編集画面で該当する接続先入力欄へスクロール・フォーカスする。名前からの移動ではオン／オフを変更しない。A5〜A7の設定編集画面にもホームと同じスリムスイッチを使い、Space・Enterで操作できる。設定とホームの値は共用する。

A5の接続欄はYouTube Live・Twitch・したらばを3列で並べ、スリムスイッチでコメント取得を個別にオン／オフする。設定値を共用し、ホームと接続設定の状態表示を一致させる。Twitchの接続エラー表示中にオフにすると停止中へ切り替わり、再度オンにすると接続成功を試作内で再現する。接続欄全体と各サービスカードの背景・枠は、オン／オフで変えない。実際の外部接続は行わない。

A4は情報を詰めたことでカードの分かりやすさ・状態の色・余白が弱くなったという評価を受け、元のAを参照して作成。既存の案は維持する。

| 案 | 構成 | 比較したいこと |
| --- | --- | --- |
| A5：元のAを磨く | 接続概要 → 日常操作 → 設定カード → 独立ウィンドウ | 元のAの流れに、明確な操作と入口を加える |
| A6：操作と設定を左右に | 左に日常操作、右に設定カード。狭い画面では縦に配置 | 日常操作と設定の入口を同時に見渡せるか |

共通で、オンは緑、オフは青灰色、接続の注意は橙色にし、文字とスイッチの位置でも状態を区別。OBS表示・スマホ音声・外配信の入口は背景・枠・アイコン・説明のあるカードにする。全14領域は共通の設定編集先へ案内する。A7の声と速度はホームでも同じ試作値を編集でき、開閉や案の切替で保持する。760×560pxと縦長画面に対応し、本文が収まらない場合は縦スクロールする。

今回は見本の追加であり、正式な管理画面仕様・保存形式・公開API・本体の実装は変更しない。

追加フィードバック：A5〜A7の読み上げ・AI・音声認識カードは、オン／オフで背景と枠の色を変えない。状態の色分けはスイッチ内で行う。A5のブラウザ表示で、切替前後のカード背景・枠が同じで、スイッチの色だけが変わることを確認した。

編集画面の階層表示は不要という評価を受けてA5〜A7から削除。上部の「設定」から設定一覧へ移動でき、入力を保持する。A5の戻るボタンは上記のとおり開いた場所へ戻り、A6・A7は「設定に戻る」を維持する。

スイッチは外側の枠と塗りがない「スリム」を使用。選定済みのため見た目を選ぶ操作は閉じ、過去の比較用コンポーネントは試作資料として残す。つまみはスライドし、動きを減らす設定ではアニメーションを省く。カードの背景・枠はオン／オフで変えない。

## 元のAを改良した見本（A4）

元のAを好む評価を受け、ホームの実用性を比較する一案を追加。元のAは変更していない。

- 大きな挨拶領域を、コメントソース別の接続先・接続状態・個別の接続操作に置き換える。Twitchの接続切れからホーム内で再接続を再現できる。
- 読み上げ・AIリスナー・配信者音声認識の操作と、独立ウィンドウの表示操作を分ける。
- オン設定とは別に、準備中・待機・手動再開待ちを表示。「比べ方・記録」から異常・準備状態の見本を切り替えられる。実際の準備処理・投稿・接続・ウィンドウ生成は行わない。
- 全14領域への設定入口、設定編集中の分類表示、用途を区別したスマホ設定入口を用意する。
- 760×560pxと560×760pxでレスポンシブ表示。小さい画面では本文を縦スクロールし、接続状態と主要操作を上部に配置する。

保存状況表示・設定一覧のスクロール位置復元・初回案内は、この見本ではまだ追加していない。正式採用する挙動は別途決める。

## 比較

「比べ方・記録」から6種類の課題を選択し、計測を開始。設定画面への移動回数と本文スクロール距離を計測し、迷った場所をメモする。計測開始は入口に戻るが設定値は保つ。案の切替は進行中の計測を終了して記録する。

全14領域に入口があり、代表項目を編集できる。初期状態ではTwitch接続エラーを再現。「設定を確認」からコメント取得へ進み、再接続で解消を再現できる。現行機能の全詳細項目を複製する試作ではない。

設定・比較記録はメモリ内だけに保持し、リロードで消える。「↺」で設定と記録を初期化できる。実API・外部通信・音声出力・資格情報・永続化は使用しない。「試作の状態を見る」で操作後の全状態を確認できる。

専用ViteエントリーとCSSを使用し、本体の起動・ビルド・配布に含まれない。設定値は16案すべてで共通に保持する。
